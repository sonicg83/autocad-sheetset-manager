# Dst Manager v0.3 测试后意见
## 1. Dst文件操作优化
  - 手动输入文件路径改为拖拽文件到上传区域和点击上传区域后弹出选择文件对话框，需要验证文件类型是否为 Dst 文件
  - 未打开dst文件状态只有拖拽文件上传区域，取消现有的*打开项目*和*修订历史*按钮，上传dst文件后自动打开
  - 打开dst文件后，现有的*打开项目*按钮改为*关闭*按钮，点击*关闭*回到未打开dst文件状态
  - 点击*关闭*按钮后，应先检查是否有待处理的改动，如果有弹窗提示用户确认是否关闭

## 2. 待处理改动暂存功能
  - 增加待处理改动暂存功能，并支持启用自动保存，防止应用崩溃或误操作导致修改操作历史丢失
  - 打开dst文件后，如果存在暂存的改动，可以继续处理上次未完成的改动
  - 点击*清空*按钮，清除暂存操作记录
  - 改动全部成功变更完毕，清除暂存操作记录
  
## 3. 选择模板文件和布局的操作优化
  - 来源文件输入框改为选择文件按钮，要对文件类型进行验证，只允许dwg文件
  - 增加一个获取dwg文件所有布局名称的.net插件，用于加载dwg后通过accoreconsole运行脚本读取所有布局名，将手动输入来源布局改为下拉选择框
  - 读取布局运行脚本需要时间，可能需要做个进度条之类的提示避免用户以为程序卡死了
  - 考虑增加布局缓存，建立dwg文件hash值与布局名列表的映射关系，避免重复读取布局名
  - 布局缓存作为软件的全局缓存，当用户操作其他dst文件时，直接从缓存中获取布局名列表，无需重复读取
