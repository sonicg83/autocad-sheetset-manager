# 绑定标准工作区的属性与 DWG 命名语义恢复

日期：2026-09-22

状态：待办（未立项；来源 PLAN-DM-035 代码审查后的属性模型讨论）

关联：`RFC-INT-003`、`PLAN-DM-035`、`PLAN-DM-037`、`SPEC-DM-016`、`SPEC-DM-017`

## 背景

DST 的 `AcSmCustomPropertyValue` 只保存文本值、作用域和节点身份，不保存 Manager 标准中的“文本/枚举”“普通/映射/组合”、枚举项、映射表、组合片段或依赖关系。因此，一个由标准创建或绑定标准的图纸集，在重新进入普通 Manager 工作区后，如果只读取 DST，会退化为一组自由文本属性，无法恢复标准约束和派生语义。

同样，标准驱动的新建流程可以根据唯一的全局 DWG 命名模板生成初始文件名，但创建完成后重新进入 Manager 工作区时，现有实现尚未依据绑定标准恢复“文件名由模板驱动、禁止自由修改、输入变化后受控重算”的持续约束。

标准包继续维护独立的 `property_id` / `enum_item_id` 体系，不与 AcSm GUID 建立持久映射。标准属性与 DST 属性按“作用域 + 规范化属性名”匹配；属性改名通过标准内保留的历史名称迁移，并保留已有 DST 值和 AcSm GUID。

## 目标行为

Manager 处理图纸集时区分两种工作区模式：

1. **普通图纸集**：未绑定标准，沿用当前 DST 原生能力；自定义属性均作为文本属性编辑，不推断枚举、映射或组合语义。
2. **绑定标准的图纸集**：通过只读保留属性 `DSTManager.Standard = <standard-id>@<version>` 解析精确标准及项目快照，在工作区投影层恢复标准属性模型并套用对应约束。

绑定标准模式至少应恢复以下语义：

- 普通属性的作用域、文本/枚举类型、必填、默认值、枚举列表和说明；
- 映射属性与组合属性的定义、依赖关系和只读状态；
- 源属性变化后的确定性重算，并将派生结果物化为 DST 中真实的文本型自定义属性值；
- 映射源必须是普通枚举属性、源属性唯一性、作用域可见性及组合字段可选范围；
- 枚举列表变化后的映射确认状态与发布 warning；
- 属性历史名称迁移：按“作用域 + 当前名称”优先匹配，未命中再匹配唯一历史名称；迁移时保留值和 AcSm GUID；新旧名称并存时阻断自动合并；
- 标准属性在工作区中的编辑权限、错误和 warning 由后端规则裁决，前端只呈现状态，不复制最终校验逻辑。

绑定标准模式还应恢复 DWG 命名约束：

- 从绑定标准读取唯一的全局 DWG 命名模板；模板字段只允许 `subset.scope`、`subset.name`、`subset.sequence` 以及 `sheetset` 作用域属性，不允许引用 `sheet` 属性；
- 将 DWG 文件名显示为标准驱动的只读结果，不允许通过直接编辑文件名绕过模板；工作区路径重绑定只改变目录边界，不改变模板派生的文件名；
- `sheetset` 属性、`subset.name`、子集物理顺序或子集图纸范围变化时，在同一确定性预览中重算目标文件名；
- 预览同时展示旧文件名、新文件名、受影响 DST 引用和实际文件移动；多个子集求值得到同一大小写不敏感目标路径时，以 `DWG_TARGET_COLLISION` 阻断；
- 正式发布继续使用现有多文件事务完成 DWG 改名与 DST 路径更新，任何失败整批回滚；不得因标准绑定新增直接移动或覆盖文件的旁路；
- 普通图纸集继续使用 Manager 当前受控命名逻辑，不套用标准模板锁定。

## 关键边界

- 标准包内部 ID 只用于标准规则引用，不能写入或替代 `AcSmCustomPropertyValue.ID`。
- 属性作用域变更不按改名迁移处理；首版应禁止直接变更作用域，要求删除后重新创建。
- 派生属性虽在 DST 中物化为文本值，但在绑定标准工作区中必须显示为标准驱动、只读，不得因 DST 存储形态而开放自由编辑。
- 标准缺失、版本缺失、快照损坏或受信依赖缺失时，不得静默按普通图纸集继续可写；应进入明确的标准能力降级状态，保留原 DST 可读性并阻止可能破坏标准语义的编辑。
- 打开工作区仍遵守只读原则：解析绑定和计算有效属性模型不得创建 `.dst-manager/`、修改 DST/DWG 或更新时间戳。
- 正式写入必须继续经过现有草稿、预览、基准修订、发布事务和永久 before 快照，不得新增旁路。

## 预计影响范围

- 工作区打开与标准解析：把 `unbound` / `resolved` / `missing` 等绑定状态提升为工作区能力判定输入；
- 领域模型：新增“DST 原始文本值 + 标准属性定义 + 有效约束/派生值 + 有效 DWG 命名模板”的投影，不污染 AcSm DOM 模型；
- 属性编辑命令：按工作区模式生成不同的可编辑字段和后端门禁；
- 标准规则求值：在普通属性变化、应用标准、预览和发布时统一重算派生属性；
- Web 属性与结构工作区：清楚显示普通图纸集与绑定标准图纸集模式、属性类型、文件名只读来源和诊断；
- 标准校验/报告：复用同一有效属性模型，避免编辑器、发布和报告各自解释标准；
- 迁移与测试：覆盖普通/绑定/标准缺失三种模式、跨版本属性改名、枚举变化、派生重算、DWG 命名重算/冲突/事务回滚以及只读打开零写入。

## 完成条件

- 同一 DST 在未绑定和绑定标准时分别呈现自由文本与标准约束行为，且模式判定可测试、可诊断；
- 关闭并重新打开绑定标准工作区后，普通/枚举/映射/组合语义与关闭前一致；
- 修改普通源属性后，映射与组合属性按拓扑顺序重算，预览与最终写入结果一致；
- 属性改名能从历史名称迁移并保留每个现有值；冲突时明确阻断，不静默覆盖；
- 绑定标准工作区内无法直接修改 DWG 文件名；命名输入变化后，预览、文件事务和 DST 引用使用同一个确定性结果；
- DWG 目标冲突或改名失败时不发布半成品，正式 DST/DWG 保持发布前状态；
- 标准不可解析时不会把标准驱动属性悄然降级为可自由编辑文本；
- 工作区打开的只读零写入测试、API 集成测试和 Web E2E 均覆盖上述行为；
- 相关 Spec、用户指南、API 契约和 `changelog.md` 随实施同步更新。

## 触发立项条件

- 开始实现“绑定标准项目在普通工作区持续受约束”的用户流程前；
