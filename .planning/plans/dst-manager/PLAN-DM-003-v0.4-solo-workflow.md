# 阶段 3：v0.4 单人工作流与维护支持

状态：待实施  
建议周期：2 周  
前置条件：v0.3 的受控编辑器、草稿、全写入摘要校验和修复状态呈现已稳定。  
阶段目标：减少单人重复打开工程、检查模板和处理故障的成本，同时保持 DST/DWG 发布安全、派生字段约束和本地隐私边界。

## 1. 成功标准

- 用户可安全管理最近项目、受检查模板和本地工作区偏好，不在只读打开时写入工程目录。
- 健康检查能同时说明 DST 修复状态、路径/模板/CAD 可用性、锁、发布恢复和未完成任务。
- CSV 能区分“属性定义维护”和“图纸属性值维护”两种契约；图号、标题、范围、DWG 文件和布局保持导出可读、导入只读。
- CSV 导入与界面编辑使用同一受控命令、预览摘要、发布事务和修复门禁。
- 诊断包便于支持定位，但默认排除绝对路径、工程内容、令牌和其他敏感信息。

## 2. 工作包

### E3-01 最近项目与工作区偏好

- [ ] 在应用数据目录保存最近项目、显示偏好和显式移除记录；不扫描或上传用户工程。
- [ ] 打开最近项目时重新执行只读检查、修订采样和修复状态判定，不信任历史缓存。
- [ ] 为失效路径、已移动工程、锁冲突和修订变化提供可理解的恢复入口。

### E3-02 受检查模板登记

- [ ] 将 v0.2.1 已有的模板检查能力扩展为本地模板登记、命名、重新检查和移除流程。
- [ ] 模板登记保存来源身份、允许的布局和检查结果；使用时再次复核来源基准。
- [ ] 模板来源仍受路径、名称、CAD 版本与布局契约校验，不允许任意文件路径进入 CAD 或 SCR。

### E3-03 CSV 双契约

- [ ] 保持 v0.2.1 已交付的自定义属性定义 CSV 契约，不重复实现或改变其既有语义。
- [ ] 新增图纸/图纸集/子集既有自定义属性值的 CSV 导入导出；稳定对象标识、属性名、作用域和基准信息必须可审计。
- [ ] 导出图号、标题、范围、DWG 文件和布局作为只读参考列；导入这些列或企图改变结构位置时稳定拒绝。
- [ ] 导入先生成与界面编辑一致的逐项预览，再以当前预览摘要和基准修订执行。
- [ ] 为空值、重复标识、作用域冲突、非法 Unicode、未知属性和基准漂移提供物理行号诊断。

### E3-04 健康检查、恢复与诊断包

- [ ] 健康检查汇总 DST 修复状态、模板、DWG 路径、CAD 2016/2020 可用性、锁、暂存/发布恢复和任务状态。
- [ ] 明确区分只读诊断、可确认修复和需要人工处理的阻断；健康检查不得修改 DST/DWG。
- [ ] 生成脱敏诊断包，包含版本、能力检查、稳定错误码、任务/发布摘要和用户选择的最小日志范围。
- [ ] 诊断包默认排除绝对路径、DST/DWG/XML 原文、模板内容、凭据和令牌；导出前显示内容清单。

## 3. 重点修改入口

- `src/dst_manager/application/`：最近项目、模板登记、CSV 预览与健康检查编排。
- `src/dst_manager/interfaces/`：CSV、健康检查、诊断包和本地偏好 API。
- `src/dst_manager/infrastructure/`：应用数据目录、模板检查、发布恢复和脱敏日志适配器。
- `web/src/`：最近项目、模板、导入预览、健康检查和诊断包交互。
- `tests/integration/` 与 `web/tests/e2e/`：双契约 CSV、恢复、隐私和端到端流程。

## 4. 测试矩阵

- [ ] 最近项目失效、工程移动、只读打开和修订变化测试。
- [ ] 模板登记、重新检查、来源漂移、危险路径和 CAD 版本不匹配测试。
- [ ] 属性定义 CSV 与属性值 CSV 的正反向、行号诊断、只读派生列和摘要校验测试。
- [ ] `VALID`、`REPAIRED`、两个 `INVALID_*` 状态下的 CSV/健康检查门禁测试。
- [ ] 发布中断、启动恢复、锁冲突和诊断包脱敏回归测试。
- [ ] Playwright 覆盖最近项目、模板、CSV 预览、修复状态、健康检查和诊断包内容确认。

## 5. 阶段验收

- [ ] 用户可在本地恢复常用工程和受检查模板，失效状态不会静默复用旧结果。
- [ ] 两类 CSV 契约清晰分离，派生字段不能经 CSV 修改。
- [ ] CSV、界面编辑和修复确认共享同一预览与事务边界。
- [ ] 健康检查能定位恢复、修复、CAD、模板和路径问题；诊断包不泄漏默认禁止的信息。
- [ ] Ruff、相关 pytest、Web 构建与 Playwright 结果均被记录。

## 6. 风险与回退

- 最近项目和模板登记仅为本地辅助数据，不能替代每次打开时的文件身份与修订检查。
- CSV 不得成为绕过领域派生或发布事务的后门；失败导入不得写入工程文件。
- 诊断导出遵循最小化原则，任何可选敏感内容都需用户明确选择。
