# 阶段 4：v1.0 Windows 产品化与发布资格

状态：待实施  
建议周期：1～2 周，另加真实项目试用期  
前置条件：v0.3、v0.4 的验收完成，`SPEC-DM-004` 的正式状态与真实 CAD/官方 Sheet Manager 发布门禁已明确。  
阶段目标：把已具备单入口启动、运行日志、受控发布和 CAD 分流基础的本地工具，交付为可安装、可升级、可恢复、可支持的 Windows 产品。

## 1. 成功标准

- 安装、升级、启动、停止和卸载具有明确的 Windows 行为；服务继续只监听 `127.0.0.1`。
- 现有单入口启动和运行日志被复用并产品化，而非另起一套不兼容的运行模型。
- 数据库迁移、应用数据、草稿、模板登记、任务/发布恢复和日志保留具有可验证的升级与回退策略。
- 产品运维界面展示当前 CAD 分流和并发模型：默认 4、允许 1～10；不再引用已废弃的 1/2/4 或自由排序/跨子集移动能力。
- 正式发布资格包含修复门禁、发布事务、双版本 CAD 和官方 Sheet Manager 显示验证的实际证据或明确的环境阻塞记录。

## 2. 工作包

### P4-01 安装包与单入口运行

- [ ] 设计 Windows 安装、升级、卸载和修复安装流程，明确安装目录、应用数据目录、日志目录及权限。
- [ ] 将现有启动脚本/单实例/运行日志能力纳入安装后的单入口启动器，保持本地环回监听和端口冲突诊断。
- [ ] 提供前台退出、异常退出、服务重启和浏览器打开失败的可理解恢复行为。
- [ ] 记录运行环境、版本、配置摘要和 CAD 可用性，禁止记录凭据、令牌和工程内容。

### P4-02 升级、迁移与回退

- [ ] 为数据库、应用数据和必要配置建立版本化迁移、迁移前备份和启动前恢复检查。
- [ ] 在新安装、从 v0.2.1 升级、迁移中断和回退后验证最近项目、模板登记、草稿、任务与发布恢复状态。
- [ ] 迁移失败时保持工程 DST/DWG 不变，并提供可执行的恢复路径和稳定错误码。

### P4-03 运行维护与保留策略

- [ ] 为永久 before 快照、发布日志、任务目录、诊断包和临时文件设计按容量、年龄和安全状态分层的保留策略。
- [ ] 清理只能处理可证明属于应用且已结束的对象；遇到不明身份、未完成发布或恢复失败时 fail-closed 并保留诊断。
- [ ] 在产品界面显示存储占用、可清理候选、恢复状态和保留策略，不默认删除用户工程内容。

### P4-04 发布资格与真实工程验证

- [ ] 固化安装/升级/卸载、迁移恢复、单实例、日志、诊断和清理的自动化验证。
- [ ] 使用私有真实工程副本完成 AutoCAD 2016/2020 的 `none`、`rename_only`、`rebuild`、失败回滚和恢复验证。
- [ ] 在官方 Sheet Manager 中验证可修复加载、受控发布后的显示和打开行为；记录工具版本、样本身份和结果。
- [ ] 以用户代表工程完成试用，收集可复现问题并只将匿名化结论归档。

## 3. 重点修改入口

- `scripts/`、启动入口和安装器配置：单入口、单实例、升级/卸载。
- `src/dst_manager/application/` 与 `infrastructure/`：迁移、恢复、保留和运行诊断。
- `migrations/`：升级/回退路径和全新数据库验证。
- `web/`：运行状态、存储、恢复、诊断与产品设置。
- `tests/`、`web/tests/e2e/` 与真实 CAD 测试：发布资格矩阵。

## 4. 测试矩阵

- [ ] 新安装、重复安装、升级、迁移中断、恢复和卸载测试。
- [ ] 单入口启动、单实例、环回监听、端口冲突、异常退出和重启测试。
- [ ] 新数据库升级、现有应用数据迁移、回退和发布恢复测试。
- [ ] 保留策略、清理边界、身份不明对象和磁盘压力下的 fail-closed 测试。
- [ ] AutoCAD 2016/2020 与官方 Sheet Manager 发布资格矩阵；环境不可用时记录阻塞条件和恢复步骤。

## 5. 阶段验收

- [ ] 用户能以单一受支持入口安装、启动、升级、停止和卸载产品。
- [ ] 升级或异常中断后，应用数据与发布状态可恢复，工程 DST/DWG 不被迁移流程破坏。
- [ ] 存储保留和清理可解释、可审计，且不误删用户工程。
- [ ] 运行界面与文档反映当前受控编辑、修复门禁及 1～10 CAD 并发模型。
- [ ] 自动化验证、双版本 CAD 和官方 Sheet Manager 验收结果均可追溯；未满足的环境门禁不得标记为通过。

## 6. 风险与回退

- 安装器、迁移或清理不得直接覆盖 DST/DWG，也不得绕过锁、暂存、发布日志和回滚。
- 版本升级需先在应用数据备份上演练；无法证明安全时停止升级并保留恢复材料。
- 真实工程试用只使用私有副本，文档与诊断不记录真实客户路径或内容。
