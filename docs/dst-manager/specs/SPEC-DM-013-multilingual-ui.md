# DST Manager 多语言界面与本地化契约规范

> 状态：已接受；G0～G7 自动验证部分已闭合（G7 有批次三遗留 e2e 回归待修复），G8 待用户裁决 D3，G9 待真实桌面执行——统一以 [PLAN-DM-021](../../../.planning/plans/dst-manager/PLAN-DM-021-multilingual-support.md)「实际验证」与 MEMO-DM-025/026 为准。
> 权威边界：ARCH-DM-005 决定语言架构与契约方向；本文决定用户可见行为、状态和验收；[双语交互 Demo](../mockups/SPEC-DM-013-multilingual-demo.html)仅作为 G4 视觉与交互基准。

## 1. G0 立项与范围

### 1.1 变更等级

本功能为 GUIDE-DM-001 定义的 **L 级跨域改动**：影响共享应用外壳、全部业务页面、设置中心、API 错误、SSE 状态和桌面 ShellBridge。实施必须拆成可独立验收的批次，不允许一次性替换全部中文文案。

### 1.2 首期范围

- 支持简体中文 `zh-CN` 与英文 `en-US`；
- 新安装默认跟随 Windows/WebView2 语言；
- 设置中心提供语言选择并持久化，保存成功后无需重启立即切换；
- 覆盖桌面 UI、设置元数据、用户可见 API/CAD 错误、原生文件对话框、日期和数字格式；
- 保持两种语言下相同的工作区、草稿、任务、修订和发布行为；
- 建立翻译键完整性、响应式、可访问性和真实 WebView2 验收门禁。

### 1.3 非目标

- 不翻译 CLI、运行日志、操作日志、项目文档和代码注释；
- 不翻译或改写 DST/DWG 中的图纸名称、图号、布局名、属性名、属性值和用户输入；
- 不提供远程语言包、在线翻译、翻译管理平台或用户自定义语言包；
- 不重新设计既有页面结构、导航模型、业务流程或主题令牌；
- 不支持“旧桌面壳 + 新前端”的跨版本组合。

## 2. G1 用户目标与成功标准

### 2.1 用户任务

1. 首次启动时直接看到与 Windows 显示语言匹配的界面，不经历明显的语言闪烁。
2. 在设置中心识别当前语言来源和生效语言，选择“跟随系统”“简体中文”或“English”。
3. 保存成功后在原位置继续工作，当前页面、输入、选区和任务状态不丢失。
4. 保存失败时继续使用原语言，并能读懂逐字段错误或冲突恢复提示。
5. 在英文界面完成与中文相同的打开、编辑、预览、发布、修订恢复和设置任务。

### 2.2 可观察成功标准

- 中文系统首次启动为 `zh-CN`，其他可识别系统语言首次启动为 `en-US`；无法读取系统语言时回退 `zh-CN`；
- `ui_locale` 保存成功后一个 Vue 渲染周期内完成全局切换并更新 `<html lang>`；
- 保存失败、冲突或 schema 阻断时生效语言不变；
- 中英文语言包键集合及插值参数集合完全一致，生产构建不出现缺键；
- 关键流程在两种语言下都可完成，不因英文伸长出现阻断性截断、遮挡或整页横向滚动；
- 原生文件对话框只能使用登记的 `dst`、`template`、`exe`、`dll` 类型，显示文本不能改变扩展名白名单；
- 语言切换前后 DST/DWG 字节、工作区修订、草稿命令和任务状态不发生变化。

## 3. G2 用户流程与状态

### 3.1 首次启动与恢复启动

1. 启动入口在挂载 Vue 前请求设置快照；
2. `ui_locale` 为显式语言时直接采用；为 `system` 时解析 `navigator.languages`/`navigator.language`；
3. 设置读取成功后初始化唯一 i18n 实例、更新 `<html lang>` 并挂载应用；
4. 设置读取失败时按系统语言继续启动，显示非阻断错误，不阻断打开工作区；
5. 已保存的文件覆盖优先于 `DST_MANAGER_UI_LOCALE`，环境值优先于默认值。

### 3.2 设置切换

1. 用户从顶部设置入口打开既有设置对话框；
2. “界面”分组置于常规配置首位，语言字段使用单选控件；
3. “跟随系统”同时显示当前解析结果，例如“跟随系统（当前：简体中文）”；
4. 用户改变选择后只形成设置编辑缓冲，全局界面暂不切换；
5. 用户点击“保存”，按钮进入忙碌状态并保留焦点；
6. 保存成功后更新设置快照、切换全局语言、更新 `<html lang>`，对话框保持打开并显示本地化成功反馈；
7. 用户取消或放弃未保存修改时继续使用原语言。

### 3.3 保存失败与错误恢复

- `422`：对话框保持打开，生效语言不变；顶部错误摘要取得焦点，每条错误链接到对应字段，字段旁保留行内错误；
- `409 SETTINGS_CONFLICT`：保留本地选择，刷新服务端修订，提示用户重新保存或取消；不得自动切换语言；
- schema 阻断：语言字段与其他设置一起只读，界面继续使用启动时已解析的语言；
- 网络或 5xx：保留编辑缓冲，显示当前生效语言的通用保存失败提示；
- 缺失翻译键：开发态显式报警，运行时回退 `zh-CN`；发行构建必须在此之前失败；
- 未知第三方错误：显示当前语言的通用摘要，原始消息只进入可展开诊断详情。

### 3.4 原生文件对话框

1. 前端按当前生效语言生成对话框描述；
2. 前端调用 `select_file(file_kind, localized_description)`；
3. ShellBridge 只按 `file_kind` 选择固定扩展名；
4. 取消继续返回 `null`，不改变表单或工作区；
5. 浏览器开发态没有桥时，设置“浏览”按钮禁用，既有无壳路径输入流程保持可用。

### 3.5 状态矩阵

| 状态 | 用户可见结果 | 语言是否变化 | 输入/工作状态 |
| --- | --- | --- | --- |
| 启动设置加载中 | 启动壳或空白底色，不先渲染错误语言的完整应用 | 尚未确定 | 不创建工作区副作用 |
| 设置加载成功 | 以解析语言一次挂载 | 是 | 设置快照成为基线 |
| 设置加载失败 | 按系统规则挂载并显示非阻断提示 | 是 | 可继续打开工作区 |
| 语言未修改 | 显示当前来源与选择 | 否 | 无脏字段 |
| 语言已编辑未保存 | 语言行显示待保存状态 | 否 | 其他设置编辑保留 |
| 保存中 | 保存按钮忙碌，重复提交禁用 | 否 | 焦点保持在保存操作 |
| 保存成功 | 对话框及背景应用同步切换，显示“已保存” | 是 | 当前页面和输入保持 |
| 422/409/5xx | 当前语言显示错误与恢复动作 | 否 | 本地编辑保留 |
| schema 阻断 | 设置只读，诊断可见 | 否 | 不写设置文件 |
| 缺翻译键 | 开发报警；生产构建阻断 | 运行时回退 | 业务行为不变 |
| 英文长文案 | 完整显示或通过明确入口读取全文 | 已切换 | 不遮挡主要操作 |
| 200% 缩放/最小视口 | 对话框内容区滚动，页脚操作可达 | 已切换 | 不产生整页横滚 |

## 4. 需求条目

| ID | 要求 |
| --- | --- |
| I18N-01 | 全应用只有一个 `vue-i18n` 实例，支持 `zh-CN`、`en-US` 和 `zh-CN` 缺键回退。 |
| I18N-02 | `ui_locale` 仅允许 `system`、`zh-CN`、`en-US`，默认 `system`，保存到全局 settings.json。 |
| I18N-03 | 语言解析遵循“显式值 → 系统语言映射 → `zh-CN` 无法读取回退”，非中文系统语言映射 `en-US`。 |
| I18N-04 | 启动时先确定语言再挂载 Vue；设置读取失败不得阻断应用。 |
| I18N-05 | 只有设置保存成功后才即时切换；失败、取消和冲突均保持原语言。 |
| I18N-06 | 切换时同步更新 `<html lang>`，保留页面、焦点、选区、未保存输入、草稿和任务状态。 |
| I18N-07 | 所有用户可见静态文本、ARIA、tooltip、placeholder、Toast 和确认文案使用语义键。 |
| I18N-08 | 动态句子使用命名参数、数字/日期格式与复数规则；禁止在调用点拼接可翻译句子。 |
| I18N-09 | 设置元数据使用 `label_key`、`category_key`、`text_key`、`file_filter_key` 和稳定 `file_kind`。 |
| I18N-10 | 422 字段错误使用稳定设置键、`message_key` 和结构化参数；参数不得包含本地化 label 或完整句子。 |
| I18N-11 | 已知 API/CAD/Shell 错误使用稳定 `code`、`message_key` 和参数；未知原始消息只作诊断详情。 |
| I18N-12 | SSE 和任务继续传输稳定状态码，语言不得进入任务、草稿、数据库或操作日志。 |
| I18N-13 | ShellBridge 根据 `file_kind` 固定扩展名；本地化描述不能改变允许类型。 |
| I18N-14 | 中英文键和插值参数集合必须构建期一致；不得把运行时回退当作交付策略。 |
| I18N-15 | 英文界面、最小视口、浅深主题和 200% 缩放不得阻断关键任务。 |
| I18N-16 | DST/DWG 内容、用户输入、路径、图号、属性值、版本、协议字段、错误码和状态码保持原样。 |
| I18N-17 | 兼容中文字段和前端 `code` 映射只存在于迁移窗口，阶段三验收时经调用方检查后删除。 |
| I18N-18 | 真实 WebView2 分别验证中文、英文和非中英 Windows 语言解析，不能只用浏览器 mock 替代。 |

## 5. G3 视觉与交互方向

### 5.1 选定方向

沿用 SPEC-DM-006 的应用外壳、SPEC-DM-011 的设置对话框、现有主题令牌和控件层级，不引入独立语言页面、顶部常驻语言切换器或首次启动向导。语言属于低频全局偏好，放在设置中心“界面”分组首项。

语言选项使用既有 enum 单选模式，语言名称保留自称形式以便用户在误切语言后仍能识别：中文界面显示“跟随系统（当前：简体中文） / 简体中文 / English”，英文界面显示“Follow system (current: English) / 简体中文 / English”。

### 5.2 淘汰方向

- 不使用顶部栏常驻切换器：占用高频工作空间，并把低频设置提升为主操作；
- 不使用启动向导：首期只有一个偏好，增加额外阻断步骤；
- 不在选择单选项时立刻切换：若随后取消或保存失败，会造成界面状态与持久化状态不一致。

### 5.3 文本伸长与可访问性

- 标题、动作、安全警告和错误正文不得只用省略号隐藏关键信息；
- Flex/Grid 文本子项允许收缩并按内容增高，长路径使用 `overflow-wrap:anywhere`，表格仅在自身容器横滚；
- 表单字段有可见 label，逐字段错误与错误摘要并存；保存失败后错误摘要可聚焦并链接字段；
- 切换后的对话框保持焦点、Esc、焦点圈闭和关闭后归还；
- 浅深主题均使用现有语义颜色，状态不能只靠颜色表达。

## 6. G4 设计冻结

### 6.1 Demo

[SPEC-DM-013 双语交互 Demo](../mockups/SPEC-DM-013-multilingual-demo.html)提供以下可复现状态：

- 中文与英文应用壳；
- “跟随系统 / 简体中文 / English”选择；
- 保存成功后即时切换；
- 保存失败时保持原语言与编辑值；
- 1440×900 与 900×768、浅色与深色；
- 英文长文本、逐字段错误和原始诊断详情边界。

冻结截图：

- [中文浅色 1440×900](assets/SPEC-DM-013/settings-zh-CN-light-1440x900.png)；
- [英文深色 900×768](assets/SPEC-DM-013/settings-en-US-dark-900x768.png)。

### 6.2 Demo 与生产差异

- Demo 使用内存快照，不读写 settings.json，不调用 API 或 ShellBridge；
- 系统语言由场景选择器模拟，不能代替真实 WebView2 验收；
- Demo 只复现应用外壳、设置中心和代表性内容，不复制全部业务页面；
- Demo 中错误 payload 为固定虚构数据，正式结构以 ARCH-DM-005 §6.2 为准。

### 6.3 冻结条件

用户已于 2026-09-09 确认语言字段位置、保存后切换时机、错误时不切换、英文伸长处理、最小视口与浅深主题。Demo 与两张关键状态截图冻结于 commit `3ecb754`；生产实现不得改变这些交互语义，视觉差异在 G8 逐项记录。

## 7. 测试与验收

### 7.1 自动化

- Python 单测与 API 集成测试覆盖设置字段、env/file 优先级、元数据键、422 结构和 ShellBridge 白名单；
- 前端单元测试覆盖语言解析、键集合/参数一致性、切换事务与错误回退；
- Playwright 继续运行中文全量回归，并为英文运行启动、设置、图纸、属性、修订、任务和发布关键矩阵；
- `npm run build` 必须包含语言包完整性扫描，新增用户可见硬编码进入允许清单审查；
- 打包静态守护（`tests/unit/test_packaging_spec.py`）：spec datas 必含 `web\dist`，生产 JS 同时嵌入中英全部 8 域语言资源且不回指源码目录；
- 切换前后使用测试夹具断言工作区身份、命令、选区和任务状态不变；语言设置事务前后工作区 DST/DWG 的 SHA-256 与 mtime 不变（自动化层已验证，打包壳复验属 G9）。

### 7.2 设计 QA 与真实验收

- G8 使用同数据、同视口、同主题比较 Demo 与生产截图；
- G8 检查完整正文、换行、对齐、滚动、焦点、错误摘要和 200% 缩放；
- G9 在真实 pywebview/WebView2 壳验证中文、英文和非中英 Windows 显示语言；
- G9 验证 `dst`、`template`、`exe`、`dll` 原生过滤器及取消行为；
- 真实 CAD 不属于新增能力，但既有非 CAD 核心回归不得失败。

- PLAN-DM-021 不包含需实施者临场决定的产品语义。

`accepted` 表示设计与实施边界已冻结，不代表功能已交付；G7～G9 仍以 PLAN-DM-021 的实际验证为准。
