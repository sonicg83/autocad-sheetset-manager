# DST Manager 属性页分区编辑设计规范

## 1. 背景与设计依据

v0.3.3 属性页将图纸集名称、横向密排的属性值表单、无限增长的字段定义列表、新增字段与 CSV 输入全部展开。真实工程有三十多个字段，既造成字段值截断，也让低频操作和下方内容远离首屏。

用户已确认“字段定义分页、图纸集属性按原顺序平铺且最多两列、两面板独立折叠”的方向；不再使用概念图中的人为属性分组。本文仅定义属性标签；图纸属性值的单行和批量编辑属于 [SPEC-DM-009](SPEC-DM-009-sheets-workspace-ui.md)。

公共外壳、令牌、操作矩阵及安全门禁引用 [SPEC-DM-006](SPEC-DM-006-dst-manager-desktop-ui-ux.md)。[原型](../mockups/SPEC-DM-006-shell-demo.html) 是风格参考，不以其少量模拟字段代替真实数据量验收。会话生成图中的局部文案与业务值不是契约，尤其不能把全局“预览变更”替换为“加入草稿”。

## 2. 范围与非目标

范围：属性字段定义的搜索、作用域筛选、分页与增删入口；图纸集名称和属性值表单；CSV 模板、导出、导入操作的渐进展示。

不增加字段数据类型、字段重命名、既有定义默认值的直接编辑、类型转换、必填配置或前后端属性分组模型；不把默认值与当前值互相替代；不创建自动混合发布批次。自定义属性值统一按文本编辑。后端 API、CSV 格式、壳桥与草稿命令保持兼容。

## 3. 页面结构

- 外壳、标签、任务浮层与 ActionDock 保持不变。内容区从上到下为“属性字段定义”“图纸集属性值”两个独立白色面板。
- 两个面板独立折叠，不强制互斥。默认字段定义折叠、属性值展开；同一工作区会话内恢复展开状态。折叠仅隐藏内容，不提交、不清空输入、不取消 CSV 操作；重新展开保留查询、页码、错误和输入。
- 标题栏始终显示字段数、未加入草稿/待写入数量与错误数量；字段定义面板有 CSV 流程时同时显示其状态。折叠不是事务隔离或清空草稿的替代方案。错误摘要可展开对应面板并聚焦错误字段。
- 面板统一标题栏、细边框、浅阴影和令牌化间距。去掉单独占满横向空间的图纸集名称条；名称并入属性表单。
- 字段定义以分页控制高度，不采用无限纵向长表，也不额外嵌套纵向滚动条。整个标签内容只有一个主要纵向滚动区域。
- 图纸集属性按原顺序平铺，最多两列，不创建业务字段组；内容不足两列的可用宽度时改为一列。标签宽度约 112–140px、常规输入宽度约 240–360px；长值可独占整行，不机械拉满窗口。
- 属性值本轮不分页，使用平铺、搜索和“仅看修改”辅助核对；字段定义仍每页 6 条。大量属性的后续性能优化不得自动改变此交互。
- 表单按可用宽度布局，不把任意数量的字段挤进同一行。大数据下允许内容区滚动，不强求三十多个输入同时出现在首屏。

## 4. 属性字段定义

### 4.1 列表与查询

- 标题栏提供“新增字段”“导入 / 导出”；查询区包括“搜索字段”和“全部 / 图纸集 / 图纸”作用域筛选。
- 表格列为字段名、作用域、默认值、操作。作用域显示中文，底层仍使用 `sheetset`、`sheet`。
- 按字段名和默认值进行当前作用域内的文本包含搜索；保持服务端定义顺序。字段身份是作用域与名称的组合，同名不同作用域不得合并。
- 默认每页 6 条；页脚显示匹配总数、当前页/总页及上一页/下一页。搜索和筛选变化回第一页；删除后当前页为空则回退至最后有效页；无结果显示清除查询入口。
- 默认值为空时显示“（空）”，长值显示摘要并可展开读取完整值；不得借用图纸集当前值填充默认值列。
- “删除”使用低强调危险文字按钮，名称包含对应字段；不能仅悬停时出现，也不允许无确认地执行正式删除。

### 4.2 新增与删除

- 点击新增后展开独立录入区，仅包含既有作用域、属性名称、默认值；字段搜索不能替代输入标签。
- 本区的字段维护仅包含新增与删除；默认值只读展示，新建时允许录入。不提供既有字段重命名或默认值直接修改，CSV 继续遵循原有合并契约。
- 使用“加入草稿”“取消”。重复字段及其他服务端错误就近展示并聚焦错误摘要，失败保留输入；成功后更新草稿投影并使该定义可见。
- 当前筛选与新增字段不匹配时，提示新增成功并提供“查看字段”，不静默更改作用域。
- 删除沿用既有草稿和确认语义；说明作用域与服务端可提供的影响范围，不虚构级联影响数量。字段定义与结构变更必须分批预览执行，冲突显示行内提示与顶部摘要。
- 不能在添加定义时偷偷把已有结构草稿清空、自动发布或拆成用户未确认的任务。
- 删除定义前若对应字段存在未提交值，先按未提交输入保护处理，再进入删除确认；不能通过折叠属性值面板绕过保护。空文本值不等于删除定义，默认值不得自动覆盖已有空值。

## 5. 图纸集属性值

### 5.1 名称、字段与文本展示

- 图纸集名称独立标注为“图纸集名称”；它不等同于自定义属性“工程名称”。两者值不得相互覆盖。
- 只渲染实际存在的图纸集属性值，保留未知名称与空值。图纸级定义不能误当图纸集值表单输入。
- 保留读取到的属性顺序；不存在的字段不补造，不根据名称映射“工程信息”“人员与出图”或“其他属性”。
- 自定义属性统一使用文本输入；数字、日期、是否等内容也不自动改为数字控件、日期控件或下拉框。出图日期年/月不得合并成新字段，不自动转换格式或裁剪用户文本。
- 长值提供足够宽度或展开编辑，保留原文本；不得因展示换行自动插入换行符或截断提交值。

### 5.2 搜索与修改筛选

- 提供一个搜索框，搜索范围为“字段名或属性值 / 仅字段名 / 仅属性值”，默认第一项；文本包含匹配，英文不区分大小写，不支持正则。属性值以当前缓冲中的文本匹配，不使用定义默认值。
- 提供“清除搜索”和“仅看修改”；后者包括未加入草稿或待写入的字段，并与搜索取交集。图纸集名称独立展示，不参与自定义属性搜索，但其修改始终计入本区提交与状态摘要。
- 显示匹配数/属性总数，以及被查询或修改筛选隐藏的修改数。过滤只影响展示，不清空缓冲或改变提交范围。
- 正在编辑的字段即使已不匹配当前搜索，编辑期间仍保持可见，标注“不再匹配当前搜索”；待用户重新搜索、清除搜索或明确结束该字段编辑后再更新结果。不得在输入过程中突然移除输入框；暂留项与实际匹配数区分。
- 提交按钮旁显示“加入草稿：共 N 项，其中 M 项当前未显示”，统计本区未加入草稿的修改，不重复提交仅处于待写入状态的字段。

### 5.3 编辑、修改标记与草稿

- 名称和属性值使用本地缓冲副本，显示修改标记；底部局部按钮明确为“加入草稿”，说明“尚未写入正式文件”。
- 修改状态以三个值区分：当前已加载正式基准值、当前草稿投影值、当前输入。输入不同于草稿值时为“未加入草稿”；草稿值不同于正式基准时为“待写入”。同一字段可同时具有两种状态，两类计数不能简单相加为不同字段数；未加载到可信基准时标为失效，不制造差异。

| 状态 | 显示规则 |
| --- | --- |
| 未加入草稿 | 琥珀色边框/浅底色，并显示“未加入草稿” |
| 待写入 | 蓝色小标记，并显示“待写入”；成功加入草稿后仍保留追踪 |
| 校验错误或冲突 | 红色边框及具体错误说明；不以红色表示普通修改 |

- 使用主题语义色并辅以文字，不能只依赖颜色。错误边框优先显示，已有修改状态文字仍保留。面板标题的状态计数折叠后仍可读取；错误数量独立统计。
- 改回对应比较基准后清除对应标记：输入回到草稿值只清除“未加入草稿”，草稿经撤销等操作回到正式值才清除“待写入”。正式写入成功并重新加载可信基准后重新计算，失败不清标记。
- 每字段提供可键盘访问的值对照：“原文件值 → 草稿值 → 当前输入”，相同阶段合并显示。提供“撤回本次输入”，仅恢复该字段当前草稿值，不撤销持久草稿；图纸集名称遵循同样规则。
- 一次提交包含本区已修改的名称和属性值，映射到既有命令，不新增批量接口。筛选隐藏的修改计入本次提交，按钮附近显示总修改数及隐藏修改数。
- 成功后以草稿投影重新建立缓冲基线；失败保留输入。提供“放弃本区输入”操作并在有变动时确认；这不清空持久草稿。
- 标签切换、字段定义分页和本区搜索保留输入。未加入草稿的内存缓冲不承诺重启恢复，不能显示为“草稿已保存”。
- 全局预览/确认、关闭工作区和基准刷新时的未提交输入保护，统一遵循 [SPEC-DM-009 §6.2](SPEC-DM-009-sheets-workspace-ui.md#62-未提交输入保护)，防止用户把未提交值误认为已纳入预览。
- 若定义删除或刷新使正在编辑的字段失效，保留输入用于核对并标记冲突，不把值提交给其他字段，也不静默丢弃。
- 成功入队但持久保存失败时仍明确显示“草稿保存失败”，不得以蓝色“待写入”暗示保存成功；重试沿用既有草稿动作，不重复加入同一修改。

## 6. CSV 与导入导出

- “导入 / 导出”菜单包含下载 CSV 模板、导出当前属性、导入 CSV，原有端点与下载语义不变。
- 选择导入后在字段定义面板展开专用区：选择文件、预览 CSV 导入、合并结果与诊断、危险确认导入。默认态不常驻文件选择器与确认按钮。
- 合并预览明确显示新增/跳过/冲突及行号；无效数据阻断确认。未选择文件、读取失败、预览失败与无变更状态均有明确说明。
- 替换文件、工作区或影响导入基准的状态变化后，旧 CSV 预览失效；不能复用旧可执行标志确认新文件。
- 确认导入是正式写入，不是加入草稿：使用 Danger 分级，保留既有强确认、影响清单、确认勾选、基准及摘要保护。与普通草稿存在冲突时遵守既有门禁，不自动合并或丢弃。
- CSV 不顺便保存属性值面板的未提交输入；正式确认前纳入未提交输入保护。选择加入草稿后如与 CSV 流程冲突，应明确说明先处理哪一批，并按原门禁阻断；不得自动发布、清空或合并。
- 提交后任务进度继续进入全局任务浮层，关闭导入区不取消已发起任务。全局 ActionDock 的普通预览不能误执行 CSV 导入。

## 7. 接口、数据、安全与兼容性

消费现有属性定义、图纸集名称、自定义属性映射、草稿投影、CsvPreview 与诊断数据。字段定义分页、查询、面板折叠及输入缓冲均为前端状态，不增加数据库表、协议字段或持久分组元数据。

正式工程文件写入的唯一公共门禁引用 SPEC-DM-006 §6.9/§9；事务与只读边界引用 [ARCH-DM-001](../architecture/ARCH-DM-001-dst-manager-mvp-baseline.md)。本页不得直接覆盖 DST/DWG、降低 CSV 确认强度或以新增字段触发隐式发布。

与图纸页共享既有草稿投影，成功增删定义后两个标签均消费同一数据源，不能维护两份最终校验规则。保留全部现有命令、错误码、撤销/重做、保存失败与冲突恢复行为。

## 8. 异常、无障碍与验收

无字段定义时显示新增字段引导；无图纸集自定义属性时仍可编辑图纸集名称，并显示新增图纸集字段入口。搜索无结果不能伪装成无字段定义。

输入关联可见标签、提示与错误；折叠面板有展开状态、分页按钮有名称和禁用语义；切换页面及关闭录入区后焦点回到有效控件。主题、键盘和读屏验收沿用 SPEC-DM-006 §7，不能只通过截图宣布无障碍达标。

| 编号 | 验收条件 |
| --- | --- |
| P-01 | 36 个定义默认只展示 6 条，分页、作用域筛选与搜索正确；下方属性区不被无限长表推远 |
| P-02 | 同名不同作用域、空默认值、长文本、删除最后一页最后一条均正确显示 |
| P-03 | 三十多个实际属性按原顺序平铺、最多两列、不分页不分组；全部为文本输入，名称与工程名称不串值 |
| P-04 | 隐藏修改仍有计数；切换、取消、失败、刷新冲突和重开草稿语义明确且无输入静默丢失 |
| P-05 | 定义与结构变更分批门禁有效；局部加入草稿不触发正式写入 |
| P-06 | CSV 的选择、换文件、预览、诊断、危险确认、执行进度及失败路径保留且无旁路 |
| P-07 | 1024×768、1120×768、1440×900、900×768 × 浅深主题覆盖默认、编辑、新增和 CSV 态；无整页横向溢出 |
| P-08 | 实现阶段完成相关 Playwright、生产构建、Ruff 与相关 pytest；模拟数据不得携带真实工程路径或客户资料 |
| P-09 | 两面板独立折叠，默认定义折叠/值展开；折叠后保留输入、查询、页码、错误、修改计数与 CSV 状态 |
| P-10 | 琥珀/蓝/红与文字区分未加入草稿、待写入、错误；覆盖状态并存、恢复原值、单字段撤回、值对照与保存失败 |
| P-11 | 字段名/属性值搜索、“仅看修改”、隐藏修改计数正确；编辑期间不匹配行不突然消失，提交覆盖全部隐藏修改 |
| P-12 | 空值不删除定义、默认值不覆盖空值；删除定义与缓冲冲突须先处理；CSV 不顺带保存输入或绕过分批门禁 |
