# 图纸目录 XLSX 内置扩展设计规范

> 定位：首个内置业务扩展 `dst-manager.sheet-catalog` 的权威行为与交互 Spec。扩展加载、Capability、保存授权和 Artifact 边界以 [ARCH-DM-006](../architecture/ARCH-DM-006-builtin-extension-platform.md) 为准；前端门禁以 [GUIDE-DM-001](../guides/GUIDE-DM-001-frontend-design-implementation-gates.md) 为准；G4 评审使用[图纸目录交互 Demo](../mockups/SPEC-DM-012-sheet-catalog-demo.html)。

## 1. 背景与范围

用户需要把当前 DST 中的图纸信息导出为 Excel 可直接使用的图纸目录。首版不应只是固定下载端点：后续需要按不同项目选择图纸集属性、图纸属性和组合规则，并保存可跨图纸集复用的模板。

本 Spec 覆盖：

- 独立“图纸目录”工作区页面；
- 内置默认模板和应用级用户命名模板；
- 固有字段、图纸集自定义属性、图纸自定义属性及组合表达式；
- 当前图纸集字段兼容性、空值警告和真实数据预览；
- 用户选择保存位置、XLSX 生成和成功 Artifact 登记；
- 浅深主题、键盘、视口、失败恢复和桌面壳验收。

不包含：

- CSV、PDF、多工作表、公式、图表、宏或 Excel 模板文件导入；
- 条件表达式、函数、循环、数学运算、格式化管道或脚本；
- 自动增加缺失 DST 属性、修改属性值或产生 `Change Proposal`；
- 图纸筛选、排序、分组、小计或跨多个 DST 合并；
- 通用 Artifact 管理页面和后台长任务；
- 浏览器开发态手工输入任意输出路径。

本项目为 L 级跨域变更，后端平台骨架与本独立页面作为同一纵向试点，但必须按批次独立验证。

## 2. 用户目标与成功标准

### 2.1 主要任务

1. 进入独立“图纸目录”页面并选择一个已保存模板。
2. 查看当前图纸集可用字段及模板兼容状态。
3. 用“输出列名 + 表达式”配置目录列并即时预览。
4. 将有效配置另存为可跨图纸集复用的命名模板。
5. 选择最终保存位置并导出可由 Excel 打开的 XLSX。

### 2.2 可观察成功标准

- 默认模板无需配置即可导出“图号、图名、文件名”三列。
- 用户能够生成 `{sheet.专业代码}-{sheet.number}`，结果如 `RQ-002`。
- 模板引用当前图纸集未定义的属性时，页面明确指出作用域和属性名，并禁止导出。
- 属性已定义但部分记录为空时，页面显示数量警告并允许导出，空值不被伪造。
- 用户能在原生“另存为”中选择目标位置；成功后可直接找到并打开文件。
- 页面不默认展示 Artifact、来源修订和哈希等技术信息，但后台记录完整可追溯。
- 预览和导出不修改 DST/DWG，不创建工程内 `.dst-manager/`。

## 3. 用户流程

### 3.1 主流程

1. 工作区加载且扩展可用时，宿主显示独立“图纸目录”页面。
2. 页面加载内置默认模板、用户模板、上次选择和当前工作区字段目录。
3. 用户选择模板；宿主立即对当前只读快照执行语法和字段兼容性校验。
4. 用户可修改输出列名、表达式和顺序；修改形成页面本地未保存草稿。
5. 页面防抖请求预览，显示固定数量的真实结果行、总行数、错误和警告。
6. 用户可“保存修改”或“另存为模板”；保存模板不是导出的前置条件。
7. 用户点击“导出 XLSX”；只有当前预览有效且与草稿一致时继续。
8. 桌面壳打开原生“另存为”；用户取消则回到页面，草稿和预览保留。
9. 用户确认路径后，宿主执行修订复核、生成、校验、原子保存和 Artifact 登记。
10. 成功时仅显示“图纸目录已保存到……”，并提供“打开所在文件夹”；失败时保留草稿和预览以便重试。

### 3.2 模板切换与离开

- 无未保存修改时可直接切换模板。
- 有未保存修改时，切换模板、离开页面、停用扩展或关闭工作区必须提供“保存为模板、放弃修改、留在此处”选择。
- 内置默认模板不可直接修改；首次编辑即成为未命名草稿，只能“另存为模板”。
- 用户模板允许原位保存；模板名大小写不敏感地唯一。
- 删除当前模板必须确认；删除后回到内置默认模板。删除模板不删除历史 Artifact。
- 工作区只记住上次选中的已保存模板；未命名草稿不跨重启恢复。

## 4. 字段模型

### 4.1 固有字段

首版提供三个稳定固有字段：

| 表达式 | 来源 | 输出规则 |
| --- | --- | --- |
| `{sheet.number}` | `Sheet.number` | 文本，保留前导零 |
| `{sheet.title}` | `Sheet.title` | 文本，原样输出 |
| `{sheet.file_name}` | `Sheet.layout.file_name` | 仅输出 Windows/Posix 路径共同语义下的 basename |

固有字段名称为保留标识，始终优先于同名图纸自定义属性。

### 4.2 自定义属性

- `{sheetset.<属性名>}` 引用图纸集作用域自定义属性。
- `{sheet.<属性名>}` 引用图纸作用域自定义属性。
- 两种作用域可在同一表达式中组合。
- 名称匹配沿用 DST Manager 现有大小写不敏感规则；编译后绑定当前字段目录中的规范名称。
- 图纸集属性在每一输出行重复求值；图纸属性按当前图纸求值。

普通点号形式适用于可作为单一标识符读取且不与保留名称冲突的属性。包含空格、点号、引号、方括号、花括号，或与保留字段重名时使用 JSON 字符串形式的方括号语法：

```text
{sheet["title"]}
{sheet["专业.代码"]}
{sheetset["项目 名称"]}
```

字段浏览器必须根据属性规范名称自动插入正确形式，用户不需要自行判断何时转义。

### 4.3 定义与值

- “缺少属性定义”表示模板引用的字段不在当前图纸集对应作用域的字段目录中，是阻断错误。
- “缺少属性值”表示属性已经定义，但图纸集或部分图纸的值为空，是非阻断警告。
- 缺值求值为空字符串；表达式中的固定文字和分隔符仍原样保留。例如专业代码为空时 `{sheet.专业代码}-{sheet.number}` 输出 `-002`。
- 页面必须显示缺值涉及的字段及图纸数量；不默认列出全部属性值。

## 5. 表达式语言

### 5.1 语法

表达式是按顺序连接的字面量与字段引用：

```text
expression      := (literal | field_reference | escaped_brace)*
field_reference := "{" scope ("." identifier | "[" json_string "]") "}"
scope           := "sheetset" | "sheet"
escaped_brace   := "{{" | "}}"
```

- `{{` 输出字面量 `{`，`}}` 输出字面量 `}`。
- 花括号外文字原样输出。
- 字段引用不能嵌套。
- 空表达式、未闭合引用、未知作用域、非法转义和引用后多余内容均为语法错误。
- 首版不支持函数、条件、默认值运算、循环、数学运算、过滤器或任意代码执行。
- 实现必须解析为受限结构化 token；禁止 `eval`、`exec`、Jinja2 或其他通用模板执行器。

### 5.2 规范化与摘要

解析成功后，宿主把字段引用绑定为规范作用域和规范属性名，并生成确定性 token JSON。预览摘要至少绑定：

- `workspace_id`；
- `base_revision_id`；
- 模板 Schema 版本；
- 按顺序排列的输出列 ID、列名及规范化 token；
- 扩展 ID、扩展版本和动作 ID。

任一项变化都会使旧 `preview_digest` 失效。

### 5.3 限制

首版限制用于避免异常配置拖垮页面或生成器：

- 最多 100 个用户模板；
- 每个模板 1～50 列；
- 模板名 1～80 个字符；
- 输出列名 1～100 个字符，大小写不敏感地唯一；
- 单个表达式最多 1024 个字符；
- 预览最多返回前 20 行，同时返回总图纸数。

超限必须在保存和预览前明确提示，不进行截断或静默丢弃。

## 6. 模板契约

### 6.1 数据结构

```json
{
  "template_id": "uuid",
  "name": "市政标准目录",
  "schema_version": 1,
  "columns": [
    {
      "column_id": "uuid",
      "header": "图纸编号",
      "expression": "{sheet.专业代码}-{sheet.number}"
    }
  ]
}
```

`template_id` 和 `column_id` 用于稳定识别、排序和未来升级，不能使用显示名称替代。

### 6.2 内置默认模板

内置默认模板固定为：

| 列名 | 表达式 |
| --- | --- |
| 图号 | `{sheet.number}` |
| 图名 | `{sheet.title}` |
| 文件名 | `{sheet.file_name}` |

默认模板随扩展版本交付，不写数据库、不可改名或删除。用户编辑后只能另存为新模板。

### 6.3 保存与兼容性

- 保存模板只要求 Schema、列名和表达式语法有效，不要求兼容当前图纸集。
- 选择或预览模板时再与当前字段目录进行兼容性校验。
- 不兼容模板仍保留并可编辑；列表和页面正文必须明显显示缺少的作用域与属性名。
- 扩展升级时按 `schema_version` 迁移；迁移失败保留旧 JSON 和诊断，不阻止宿主启动。

## 7. 页面结构与状态

### 7.1 选定方向

页面采用用户于 2026-09-09 选定的“表达式模板”方向：顶部选择和管理模板；左侧字段浏览器；右侧“输出列名 + 表达式”编辑区；下方或同屏提供真实结果预览和主要导出操作。

已比较但未采用：

- 左右分栏片段构建器：易上手，但复杂组合表达受限，后续演进会引入第二套高级编辑方式。
- 分步向导：单步清晰，但多列模板需要频繁往返，难以整体检查和调整。

页面沿用 [SPEC-DM-006](SPEC-DM-006-dst-manager-desktop-ui-ux.md) 的外壳、令牌、焦点、主题和任务反馈模式，不新增独立视觉语言。

### 7.2 主要区域

1. 模板栏：当前模板、兼容状态、保存、另存为、删除。
2. 字段浏览器：分为“图纸固有字段、图纸集自定义属性、图纸自定义属性”；点击将正确语法插入当前表达式光标位置。
3. 输出列编辑器：列名、表达式、校验状态、添加、删除和顺序调整。
4. 兼容性摘要：缺少定义为阻断错误；缺少值为带数量的警告。
5. 预览表：最多 20 行真实数据，显示总行数；宽列只在受控内容区横向滚动。
6. 操作区：刷新预览、导出 XLSX；导出是唯一高强调操作。

### 7.3 状态矩阵

| 类别 | 必须覆盖的状态 |
| --- | --- |
| 页面 | 初始、加载、可用、空图纸集、加载失败、扩展停用、不兼容 |
| 模板 | 内置、用户模板、未命名草稿、已修改、保存中、保存失败、删除确认 |
| 表达式 | 有效、语法错误、未知字段、列名重复、超限 |
| 数据 | 全部有值、部分空值、图纸集字段缺失、图纸字段缺失、长字段名、长结果、大图纸集 |
| 预览 | 防抖等待、请求中、成功、过期、失败、修订漂移 |
| 导出 | 无桌面壳、选择路径、取消、生成中、成功、目标漂移、写入失败 |
| 视图 | 浅色、深色、基准视口、最小支持视口、200% 缩放、键盘操作 |

错误必须出现在可见正文中，并将焦点移到首个可操作问题；不能只用颜色、tooltip 或禁用按钮解释失败原因。

### 7.4 G4 可操作 Demo

[图纸目录交互 Demo](../mockups/SPEC-DM-012-sheet-catalog-demo.html)使用去敏虚构数据覆盖模板管理、字段插入、表达式编辑、兼容性提示、预览、空图纸集和模拟原生另存为。Demo 不调用真实 API、不创建 XLSX、不写模板数据库，也不登记 Artifact；具体差异和自动化预检证据见[图纸目录 G4 Demo 自动化 QA 记录](../../../.planning/memos/dst-manager/2026-09-09-sheet-catalog-demo-qa.md)。

自动化预检不代替用户确认。用户实际操作并确认前，G4 保持“评审中”，本文保持 `review`。

## 8. 预览与执行接口

### 8.1 预览请求

```json
{
  "workspace_id": "uuid",
  "base_revision_id": "sha256",
  "template": {
    "template_id": "uuid-or-null",
    "name": "未保存草稿",
    "schema_version": 1,
    "columns": []
  }
}
```

预览响应包含：

- 规范化模板；
- 按作用域分组的当前字段目录；
- 阻断错误和非阻断警告；
- 前 20 行求值结果和总图纸数；
- `preview_digest`；
- `executable`。

只有语法、字段定义和限制全部通过时 `executable=true`。空图纸集返回只有表头意义的有效预览，`total_rows=0`，允许导出。

### 8.2 执行请求

执行请求重复提交模板快照，并携带：

```text
workspace_id
base_revision_id
preview_digest
save_grant_id
```

后端不得依赖前端缓存或仅凭 `template_id` 推断导出内容；必须重新解析模板、重新构建只读快照并核对摘要。用户模板是否已经保存不影响执行。

执行成功响应包含 Artifact ID、文件名、用户选择的保存路径和非阻断警告。普通页面不显示来源修订、哈希和扩展版本；诊断接口仍可查询。

## 9. XLSX 输出规范

- 使用 `openpyxl` 生成标准 `.xlsx`。
- 工作簿只包含一个可见工作表，名称为“图纸目录”。
- 第一行为模板配置的列名；冻结首行并启用自动筛选。
- 数据从第二行开始，按 DST 子集顺序和图纸顺序输出，不自行排序。
- 所有值以字符串单元格写入，保留 `001` 等前导零。
- 根据表头与预览/完整数据计算可读列宽并设置上限；超长内容换行。
- 不生成公式、宏、图表、外部链接、隐藏列、隐藏工作表或绝对工程路径。
- 空图纸集生成只有表头的有效工作簿。
- 建议文件名为“`<图纸集名称>-图纸目录.xlsx`”；宿主替换 Windows 非法文件名字符并限制长度，用户可在原生对话框修改。

宿主生成后必须重新打开候选文件并核对工作表数、名称、表头、数据行数和禁止特性，再执行最终保存。

## 10. 保存位置与完成反馈

- 导出前必须通过桌面壳原生“另存为”选择最终位置，固定过滤器为 XLSX。
- 用户取消时不生成文件、不登记成功 Artifact，页面草稿和预览保持不变。
- 目标已存在时使用原生覆盖确认；确认后的目标身份仍纳入保存授权和执行前复核。
- 最终文件由宿主原子保存；扩展不得接收目标路径。
- 应用数据目录只保存临时候选，成功或失败后清理，不永久保留重复 XLSX。
- 成功提示正文显示最终路径，并提供“打开所在文件夹”；Artifact 技术信息默认隐藏。
- 文件之后被移动、修改或删除不影响工作区，只影响后台 Artifact 的可用性判断。

## 11. 错误规则

| 错误码 | 用户结果 |
| --- | --- |
| `SHEET_CATALOG_EXPRESSION_INVALID` | 定位到具体列和字符位置，禁止预览与导出 |
| `SHEET_CATALOG_FIELD_UNDEFINED` | 显示缺少的作用域和属性名，禁止导出 |
| `SHEET_CATALOG_VALUE_MISSING` | 显示字段和受影响行数，允许导出 |
| `SHEET_CATALOG_COLUMN_DUPLICATE` | 定位重复列名，禁止保存、预览和导出 |
| `SHEET_CATALOG_TEMPLATE_LIMIT` | 显示具体限制，不截断数据 |
| `SHEET_CATALOG_TEMPLATE_CONFLICT` | 保留本地编辑，刷新模板修订后允许另存或重试 |
| `REPREVIEW_REQUIRED` | 保留编辑，刷新工作区字段与预览 |
| `SAVE_GRANT_INVALID` | 要求重新选择保存位置 |
| `EXPORT_DESTINATION_CHANGED` | 不覆盖目标，要求重新确认路径 |
| `SHEET_CATALOG_XLSX_INVALID` | 不保存候选文件，不登记成功 Artifact |
| `ARTIFACT_WRITE_FAILED` | 清理临时文件，保留编辑并允许重试 |

错误响应使用稳定 `message_key` 与结构化参数。属性值、完整目标路径和表达式求值结果不得进入普通日志。

## 12. 安全与只读边界

- 扩展只使用 ARCH-DM-006 定义的冻结快照，不访问数据库、AcSm DOM、工作区对象或文件系统。
- 文件名由宿主裁剪为 basename；表达式无法访问绝对路径、Handle、布局路径或未声明字段。
- 表达式解析器不执行代码，不进行动态属性访问，不允许函数调用或网络访问。
- XLSX 只包含值和受控样式，不写公式，防止用户属性被解释为公式；以 `=`、`+`、`-` 或 `@` 开头的值仍作为字符串单元格保存。
- 只有宿主处理保存授权、目标路径、覆盖基准和原子替换。
- 导出不取得工程写锁，不创建工程修订，不修改 DST/DWG 或工程内管理目录。

## 13. 兼容性与可访问性

- 扩展、模板和动作遵循 ARCH-DM-006 的版本契约；未知高版本模板不得加载为可编辑有效状态。
- 页面文案、字段分类、错误和原生对话框遵循 ARCH-DM-005 的中英文契约；DST 属性名和值保持原文。
- 所有模板、字段、列、预览和导出操作可由键盘完成。
- 表达式错误聚焦具体编辑框并提供字符位置；对话框定义 Esc、焦点圈闭和焦点归还。
- 状态同时使用文字和视觉表达；200% 缩放和最小视口下主要操作不被遮挡。
- 宽预览只允许内容区滚动，不造成整页横向溢出。
