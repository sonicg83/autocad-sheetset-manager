# DST Manager 图纸页单表工作区设计规范

## 1. 背景与设计依据

v0.3.3 已重建标签化外壳，但图纸页仍由全局浏览表、下方子集编辑表和两套常驻新增表单组成。真实数据下，长 DWG 路径挤压图号与状态列，逐行属性输入框使行高膨胀，页面滚动与表格滚动叠加。

用户已确认“左侧结构树、右侧唯一主表、属性按需编辑”的视觉方向。本文将该方向转化为可评审行为规范，不表示功能已经实现或指定发布版本。
本规范已于 2026-09-04 经用户结合交互 Demo 确认；实施安排见 [PLAN-DM-015](../../../.planning/plans/dst-manager/PLAN-DM-015-sheets-workspace-ui.md)。

- 外壳、令牌、按钮分级、无障碍和全局操作矩阵沿用 [SPEC-DM-006](SPEC-DM-006-dst-manager-desktop-ui-ux.md)。本文细化其图纸标签，不替代公共规范。
- 原始视觉参考为 [外壳演示原型](../mockups/SPEC-DM-006-shell-demo.html)。用户截图与会话生成图用于确认方向，不作为数据契约；不归档含真实工程信息的截图。
- 生成图中的 `Model` 布局、简化文件名和缺失的浮层页签不是规范：实际展示必须消费服务端值，保留实施进度、修改预览、诊断全部入口。
- 属性页由 [SPEC-DM-010](SPEC-DM-010-properties-workspace-ui.md) 单独约束。
- 功能确认使用 [图纸页交互 Demo](../mockups/SPEC-DM-009-sheets-demo.html)：独立单文件、13 张虚构图纸、12 项图纸属性，可操作导航、列配置、分页编辑、参照插入和草稿流程；文件夹、模板、预览与发布均为模拟，不连接生产服务。Demo 的简化派生值及演示上限不构成业务契约，也不表示本规范已实施。

## 2. 范围与非目标

范围：图纸导航、筛选、唯一表格、单图纸与批量属性编辑、子集标题修改、图纸和子集增删入口、内容区滚动与视觉收敛。

不改变既有业务 HTTP/SSE API、草稿命令格式、命名规则、文件事务或 CAD 分流；桌面壳桥仅扩展“打开当前图纸集所在文件夹”的受限能力。不新增多图纸集项目管理、自由图号编辑、自由排序、跨子集移动、DWG 预览或任意布局选择能力。文件与布局来源继续遵循 [SPEC-DM-008](SPEC-DM-008-v032-naming-and-template-flows.md)。

## 3. 布局与视觉

### 3.1 单一工作区

- 保留顶栏、三个固定标签、任务浮层和全局 ActionDock。默认不为无内容的任务浮层强占宽栏；已有自动展开规则不变。
- 内容区为左树右表，左侧基准宽度 240px，右侧占据剩余空间；移除重复页面标题和上下两张业务表。
- 顶栏与左侧树根显示当前图纸集名称，不使用独立“项目”层；概念图中的项目只是占位称呼，不为多图纸集管理预设业务对象。
- 左侧从内容区顶部开始，显示当前图纸集、全部图纸、子集、展开后的图纸。数量为草稿投影中的实际数量。
- 顶栏名称旁提供“打开图纸集所在文件夹”图标按钮，在 Windows 文件资源管理器打开当前 DST 所在目录并尽可能选中 DST。打开的不是模板目录，也不保证包含全部 DWG；目录不存在时明确提示，无桌面壳时禁用并解释原因。
- 主表标题显示当前范围与结果数量；全图纸集筛选时显示“全部图纸”，不沿用旧子集名称。
- 内容边距 24px、区域间距 16px，消费 SPEC-DM-006 令牌；控件采用同一圆角、边框、字体与高度体系，不保留原生黑色直角输入框。

### 3.2 滚动与窄屏

- 外壳与 ActionDock 固定，主表区域承担主要纵向滚动，表头与当前选择条保持可见；树可独立滚动，不依靠整页长滚动定位图纸。
- 表格宽度不足时不自动隐藏用户已选列；横向滚动仅限表格内部，固定选择框、图号与操作列，给其余列保留滚动空间，不挤压短列为逐字换行。
- 最小支持视口与任务浮层断点沿用 SPEC-DM-006。900px 韧性视口下树收起为可访问抽屉，保留打开入口；抽屉与任务浮层不得同时困住焦点。

## 4. 导航、筛选与选择

### 4.1 当前浏览范围

- 初次打开工作区默认浏览全部图纸；选择子集后主表仅显示该子集。
- 点击“全部图纸”只将同一张主表切换为整个图纸集的范围，不展开全部树节点、不展开行编辑、不自动勾选；保留现有搜索与筛选，并显示“匹配 X / 全部 Y 张”。
- 点击树中的图纸，切换到所属子集并定位对应行，不自动勾选。若现有筛选排除目标，显示“目标被筛选隐藏”及“清除筛选并定位”，不暗中清除条件。
- 全局搜索覆盖图号、标题、自定义属性、DWG 文件名及原有路径字段；默认作用于当前范围，提供明确“搜索全部图纸”入口。
- 搜索常驻；路径、诊断、待变更等低频筛选点击“筛选”后展开。生效条件以可清除标签展示，支持一键清除。树与范围筛选共用一个范围状态，不维护相互独立的子集选择器。
- 保留原有首屏 80 行与继续加载能力；计数区分匹配总数与已加载数。“全选当前结果”覆盖全部匹配项，而不只是已渲染行。

### 4.2 勾选集合

- 勾选图纸、树焦点和行编辑是三个独立状态，以稳定对象 ID 关联，不能以行号或标题作为标识。
- 切换范围、筛选及主标签保留勾选集合；显示“已选 N 张，其中 M 张不在当前结果”。批量操作作用于完整勾选集合，提交前明确对象数与跨子集范围。
- 取消全选只移除当前结果；“清除选择”清空全部。投影删除的对象从勾选集合移除并提示。
- 未选择时只显示选择入口，不展示批量字段和值输入；选择后出现吸顶选择条，点击“批量修改属性”展开输入。

## 5. 图纸表格与显示列配置

| 列 | 展示规则 |
| --- | --- |
| 选择 | 固定显示，约 40px，复选框有包含图号的可访问名称 |
| 图号 | 固定显示，最小 72px，不逐字换行，按服务端值只读显示 |
| 标题 | 固定显示，主阅读列，最多两行；完整值支持悬停和键盘聚焦查看 |
| 子集 | 可选；默认全部图纸范围显示、单子集范围隐藏，分别记忆用户在两种范围下的开关 |
| 文件名 | 可选，默认显示登记文件的文件名部分；不同时堆叠三种路径 |
| 布局 | 可选，默认隐藏，消费实际布局名，不写死为 Model |
| 状态 | 固定显示，最小 96px，文字加语义色；阻断与待变更可并存，不相互遮盖 |
| 图纸自定义属性 | 每个属性独立开关；首次默认展示按定义顺序排列的前三项（不足三项全部显示），图幅不作为内置固定列 |
| 操作 | 固定显示，稳定宽度，直接提供“编辑属性”“删除”，移除独立详情入口 |

普通行目标高度约 40–48px，双行标题可增高；不以压缩文字或裁掉焦点轮廓维持高度。无关正常状态弱化，有诊断的状态提供跳转入口。

筛选旁增加“显示列”按钮，弹出配置面板；固定列显示锁定状态，可选字段使用复选框，自定义属性多时支持名称搜索。第一版提供开关和“恢复默认”，不提供拖拽排序。隐藏列不影响搜索、筛选、批量修改或完整属性编辑。

配置按图纸集记忆在应用数据目录，不写入 DST 或工程目录；与当前工作区身份关联，重开同一图纸集恢复、不同图纸集不串配置。存储失败显示提示，当前会话选择仍生效；恢复默认仅影响当前图纸集。

字段定义删除后从配置中移除；撤销删除恢复此前开关。配置建立后新增的字段不自动进入表格，在配置入口提示有新字段。字段身份包含作用域与名称，不能与内置列同名冲突。

日常不设置完整路径详情页；文件名省略时可悬停或键盘聚焦读取完整文件名。路径异常仍在任务浮层“诊断”中提供登记路径、解析结果与原因，完整值可读取、复制；打开 DST 文件夹不能代替 DWG 路径排障。

## 6. 编辑与新增状态

### 6.1 单行与批量属性

- 默认所有行只读，点击“编辑属性”在该行下展开局部编辑区，一次只展开一张图纸；不把勾选动作等同于进入编辑。
- 属性输入使用编辑缓冲副本，不直接修改服务端工作区对象。图号、派生标题、范围和文件/布局派生名不可编辑。
- 编辑区最多两列，每页 6 个属性，提供属性名称搜索；页脚显示总属性数、页码和跨页已修改数。翻页和搜索仅改变展示，不丢输入、不自动提交；未在表格显示的属性仍可编辑。
- “加入草稿”提交该图纸所有属性页的修改，不能只提交当前页；隐藏页错误在摘要中提供跳转到对应页和字段的入口。图纸主表继续加载与属性编辑分页独立。
- “加入草稿”成功后更新既有草稿投影与计数，退出编辑；失败保留输入并呈现行内错误及可聚焦摘要。“取消”明确丢弃当前缓冲，不撤销已有草稿。
- 批量编辑采用“选择一个既有图纸属性 → 设置值 → 应用于完整勾选集合”，不复制单图纸的分页表单，也不在此创建定义。明确区分“设置值”和“清空值”：设置值模式空输入不生成修改，清空必须显式选择并确认影响数量，是否允许空值仍由服务端校验。批量范围不得隐式缩为当前可见行。
- 单行编辑、新增表单、子集标题编辑和批量编辑共用一个活动编辑上下文，避免多个不同提交按钮同时争夺注意力。

### 6.2 未提交输入保护

| 动作 | 行为 |
| --- | --- |
| 切换主标签 | 保留缓冲和字段错误，返回后恢复；不会自动加入草稿 |
| 切换范围、筛选导致当前编辑隐藏，或打开另一编辑上下文 | 有变动时提示“加入草稿后继续 / 放弃输入 / 留在此处”；失败留在原位置 |
| 点击全局预览或确认写入 | 有未提交输入时先执行上述决策，不能静默忽略输入；加入草稿使旧预览失效，必须重新预览 |
| 关闭或更换工作区 | 将未提交输入纳入现有关闭确认，不静默丢弃；确认后清空页面级状态 |
| 基准刷新或对象消失 | 标记编辑上下文失效，保留可见输入供核对，禁止提交到新基准或其他对象 |
| 编辑未提交时点击删除 | 先处理缓冲，再按删除确认流程操作；删除命令不得夹带未确认的属性变更 |

缓冲仅保证同一会话中的切换恢复；只有成功加入既有持久草稿的动作才承诺重开恢复。界面必须区分“尚未加入草稿”与“草稿已保存”，不得把内存缓冲称为已保存。

### 6.3 子集与图纸增删

- 标题栏提供“编辑子集”“新增图纸”“新建子集”；统一在主表上方展开表单，一次只出现一种，底部明确“取消 / 加入草稿”。表单较长时内部滚动，保留标题和取消入口。
- 编辑子集：显示当前子集、标题输入和只读图号范围，只修改子集标题。全部图纸范围下先选择编辑对象，不使用隐含的上次子集。派生图纸标题、文件名和布局名通过服务端预览确认。
- 新增图纸：目标子集、参照图纸、之前/之后、数量、模板来源。单子集范围预填目标；全部图纸范围必须明确选择。选择参照对象而非手填序号；目标变化后清除不属于新目标的参照。
- 新建子集：标题、参照子集、之前/之后、初始图纸数、基础模板文件、布局模板文件及布局。空图纸集显示“创建首个子集”，不展示不存在的参照，沿用首个序号为 1 的契约。
- 参照以稳定对象 ID 绑定，基于当前草稿投影映射为既有序号/方向命令，不增加自由排序能力。加入草稿时重新核对；参照已删除或失效时保留表单并要求重选，不静默替换对象。没有可用图纸参照的空子集，不制造虚拟参照或零序号，提示当前流程不可用；空图纸集通过新建子集并设置初始图纸数进入既有流程。
- 基础模板决定新 DWG 基底，布局模板提供布局，两者分开标注。已有布局来源不重新要求用户填写文件和布局；选择模板来源才展开对应文件与布局选择。
- 成功加入草稿后关闭表单并定位新增/编辑对象，更新到其所在范围；保留不匹配的筛选并提示清除后定位。失败保留完整输入，不展示为已创建正式文件。
- 模板选择、布局读取、加载、失败与人工输入回退遵循既有壳桥及 SPEC-DM-008，不自动替换为 Model。
- 每行“删除”直接可见，采用低强调危险文字按钮；确认文案明确“加入删除草稿”，不是立即删除文件。正式 DWG/布局影响以既有规则和服务端预览为准。
- 图纸加入删除草稿后从正常投影表和勾选集合中移除，显示反馈，可在草稿栈查看与撤销；撤销后恢复图纸，但不自动恢复勾选。
- “删除整个子集”放在编辑子集表单内独立危险操作区域，与提交按钮分隔。整子集删除继续遵循 [SPEC-DM-005](SPEC-DM-005-controlled-subset-deletion.md)，不得因入口调整削弱确认。

## 7. 接口、数据与安全边界

复用现有 Workspace/Subset/Sheet、诊断与草稿投影数据，以及现有命令和布局读取接口；HTTP/SSE、序列化字段与错误码均不变。树范围、选择集合、活动编辑上下文、输入缓冲和展示省略属于前端状态，不写入 DST。

显示列偏好是应用级本地数据，与持久草稿分开存储，不改变命令与工程文件。新增壳桥仅允许打开当前有效工作区的 DST 所在目录：由可信工作区状态解析目标，不接受前端提供的任意路径或命令；无工作区、路径无效或目录不存在均返回可呈现错误。用结构化参数调用系统文件管理器，不拼接 Shell 命令，不触发发布或创建工程文件。该壳桥扩展是本文对原“纯前端”范围的明确补充，具体接口签名在实施设计中确定。

安全事务以 [ARCH-DM-001](../architecture/ARCH-DM-001-dst-manager-mvp-baseline.md) 为基线；正式写入分类、预览摘要、基准修订和状态门禁引用 SPEC-DM-006 §6.9/§9，不在本文复制矩阵。页面整理不得启动 CAD、修改样本、绕过发布器或把用户文本拼成路径/SCR 命令。

布局重组必须保留草稿撤销、重做、冲突与保存失败反馈。全局按钮仍为“预览变更”和符合当前状态的危险确认动作；局部“加入草稿”不得替代全局预览。

## 8. 异常、无障碍与验收

- 空图纸集显示新建首个子集引导；筛选无结果显示原因与清除入口，不渲染无说明的空表头。无属性时引导到属性标签管理定义。
- 键盘模型、焦点恢复、对比度、减少动画沿用 SPEC-DM-006 §7。完整文本与编辑不能只靠悬停访问；表格、树、菜单、配置及展开按钮须有可访问名称及状态。
- 使用虚构工程数据覆盖 13 张图纸、36 个字段、超长路径、长标题、无属性、诊断与待变更并存、跨子集选择和大列表。不得将私有截图或真实路径写入公开测试夹具。

| 编号 | 验收条件 |
| --- | --- |
| S-01 | 默认只有一张图纸业务表，树从顶部开始，两种新增表单均不常驻 |
| S-02 | 树、搜索与筛选共用范围；隐藏目标的定位有显式反馈 |
| S-03 | 全选覆盖未加载结果，跨范围选择数与实际批量命令对象一致 |
| S-04 | 关键短列不逐字换行；固定列不可隐藏，可选列配置逐图纸集恢复；诊断路径与后端原值一致且可复制 |
| S-05 | 单行、批量、新增、子集编辑支持成功/失败/取消及未提交输入保护 |
| S-06 | 新增来源、整子集删除、草稿恢复及所有发布门禁无回归 |
| S-07 | 1024×768、1120×768、1440×900、900×768 × 浅深主题截图通过；浮层展开、行编辑、新增态均可达 |
