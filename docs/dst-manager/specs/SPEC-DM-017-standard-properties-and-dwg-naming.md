# 图纸标准属性与 DWG 命名规范

## 1. 目的与权威范围

本文定义图纸标准中的普通属性、派生属性和全局 DWG 命名模板，是这些领域规则及编辑交互的唯一权威规范。本文取代 [SPEC-DM-016](SPEC-DM-016-drawing-standard-management-ui.md) §6.3、§7.1～§7.3 中的属性、映射、组合与 DWG 命名设计；SPEC-DM-016 的欢迎页、标准库、模板资产、发布检查、响应式和可访问性要求继续有效。

本文覆盖：

- 普通属性和派生属性的定义、引用和编辑；
- 枚举、映射与组合的封闭求值规则；
- 标准属性与 DST 文本型自定义属性之间的关系；
- 标准驱动新建图纸集时的全局 DWG 命名模板；
- 标准草稿保存与发布检查所需诊断。

创建完成后重新进入 Manager 工作区时，如何恢复标准属性语义、锁定 DWG 文件名并在结构变化后事务改名，不在本文当前实施范围，统一登记于 [绑定标准工作区的属性与 DWG 命名语义恢复](../../../.planning/todos/dst-manager/2026-09-22-bound-standard-workspace-semantics.md)。

## 2. 设计原则与信息架构

标准编辑器不再把属性定义、普通规则、字段映射、字段组合和 DWG 命名拆成彼此重叠的规则页面。编辑分区调整为：

1. 基本信息；
2. 普通属性；
3. 派生属性；
4. DWG 命名；
5. 模板资产；
6. 版本与发布。

核心原则：

- 用户先定义属性，再定义基于属性的派生关系和 DWG 命名；
- 枚举、映射和组合是属性自身的约束或派生方式，不再作为可任意指定目标字段的通用规则；
- 不提供 JSON、脚本、通用公式、条件表达式或自由规则目标；
- 后端负责最终校验和求值，前端只提供结构化编辑、即时预览和诊断定位；
- DST 中所有自定义属性值仍是文本；“文本/枚举”“普通/映射/组合”只属于标准语义。

## 3. 属性身份、名称与作用域

### 3.1 独立身份体系

标准包为每个属性维护稳定的 `property_id`，为每个枚举项维护稳定的 `enum_item_id`。规则和令牌引用内部 ID，界面显示当前属性名或枚举值；改名不得破坏引用。

标准 ID 不写入或替代 `AcSmCustomPropertyValue.ID`。AcSm GUID 继续表示具体 DST 节点实例，由 DST/AcSm 层生成和维护；标准与 DST 按属性名称匹配，不建立持久 GUID 映射。

### 3.2 全局命名空间

- 普通属性与派生属性共享一个全局命名空间；`sheetset` 与 `sheet` 不同作用域也不允许同名，以兼容 AutoCAD 官方行为。
- 名称比较忽略首尾空格与大小写；当前名称和全部历史名称共同参与冲突检查。
- `DSTManager.*`、`sheet.number`、`sheet.title`、`subset.scope`、`subset.name`、`subset.sequence` 及其他宿主登记系统字段均为保留名称，不能创建为自定义属性。
- 属性作用域创建后不可直接修改；普通/派生类型之间也不可直接转换。需要改变时必须删除后重建，并继续受引用删除保护。
- 删除被映射、组合或 DWG 命名引用的属性时必须阻断并列出引用方，不做级联删除。

### 3.3 名称迁移

属性改名时保留历史名称。应用标准到 DST 时按以下顺序匹配：

1. 作用域 + 当前规范化名称；
2. 作用域 + 唯一历史规范化名称。

命中历史名称后，迁移对应节点的 `propname`，保留现有文本值和每个 AcSm GUID。新旧名称同时存在、一个历史名称匹配多个属性或作用域不一致时，禁止自动合并并报告冲突。

## 4. 普通属性

### 4.1 表格结构

普通属性表固定包含：

```text
属性名 | 作用域 | 类型 | 必填 | 默认值 | 枚举值 | 说明 | 删除
```

- 作用域只允许 `sheetset`、`sheet`；
- 类型只允许“文本”“枚举”；
- 文本属性的枚举值控件禁用；
- 枚举属性的枚举值可在表格内摘要显示，并通过扩展模态对话框维护完整列表；
- CSV 导入若保留，必须导入为同一普通属性模型，不得产生第二套规则语义。

### 4.2 值规则

- 枚举项不得为空或完全重复；比较和写入保留用户输入文本，不静默改变大小写或内容。
- 枚举属性的非空默认值必须属于枚举列表。
- 必填属性允许不设置默认值，但在创建或发布前必须取得非空实际值。
- 默认值只用于新建属性、新建图纸集或新建 Sheet；不得覆盖已有 DST 值，也不得在用户主动清空后自动回填。
- 既有值违反必填或枚举约束时保留原值并报告阻断错误，不自动替换、清空或改为默认值。
- 删除仍被既有 DST 使用的枚举值时保留 DST 文本，并将其标记为非法枚举值，修正前允许只读查看和保存草稿，但禁止正式创建或发布。

## 5. 派生属性

### 5.1 表格结构与共同规则

派生属性表固定包含：

```text
属性名 | 作用域 | 源属性摘要 | 类型 | 说明 | 编辑 | 删除
```

- 作用域只允许 `sheetset`、`sheet`；
- 类型只允许“映射”“组合”；
- 派生属性在使用标准创建的项目中只读；
- 点击“编辑”按类型打开映射或组合编辑模态框；
- 派生结果必须物化为 DST 中真实的文本型自定义属性值，供 AutoCAD 字段直接引用。

### 5.2 映射属性

映射编辑器由一个受控源属性选择器和一张两列表组成。当前派生属性就是目标，不提供自由目标字段输入。

约束如下：

- 源属性只能是普通枚举属性；
- `sheetset` 映射属性只能选择 `sheetset` 普通枚举属性；
- `sheet` 映射属性可以选择 `sheetset` 或 `sheet` 普通枚举属性；
- 一个普通枚举属性最多被一个映射属性用作源，不允许两个映射属性共享同一源；
- 映射表按源枚举列表初始化，源值列只读，不允许在映射编辑器内新增、删除或排序；
- 目标值必须非空，允许多个源值映射为同一目标值；
- 映射使用 `enum_item_id` 关联行，源枚举显示值改名后保留原映射结果；新增枚举项产生一个空目标行并阻止发布；删除枚举项移除对应映射行；排序跟随枚举列表；
- 枚举列表发生增删或改名后，映射进入“待确认”状态。用户检查并确认后清除状态；未确认时发布检查显示 warning。

可选源属性为空时映射结果为空，不报错。非空源值不属于枚举或未被映射表覆盖时，映射失败并阻止创建或发布。

### 5.3 组合属性

组合编辑模态框采用与图纸目录输出列编辑器一致的结构：

- 左侧为字段浏览器；
- 右侧为单行令牌编辑框；
- 下方为实时预览。

固定文本可以直接输入；字段必须从浏览器插入为不可拆分令牌。表达式仅由固定文本和字段令牌组成，不提供 JSON、脚本、条件、循环或通用公式。

字段可见性：

- `sheetset` 组合属性可以引用 `sheetset` 普通属性和 `sheetset` 映射属性；
- `sheet` 组合属性可以引用 `sheetset`/`sheet` 普通属性和映射属性；
- `sheet` 组合属性另外可以引用系统字段 `sheet.number` 和 `sheet.title`；
- 组合属性不能引用其他组合属性，也不能引用 DWG 命名结果，从结构上消除组合循环。

可选字段为空时按空字符串拼接。上游映射失败或必需系统值缺失时，组合标记为无法计算，不读取 DST 中遗留的旧派生值，也不写入部分结果。

### 5.4 求值与物化

派生求值固定为：

```text
普通属性 → 映射属性 → 组合属性
```

整条派生链成功后才把结果写入候选 DST；任何节点失败都阻止正式创建或发布，正式 DST 保持不变。外部工具手工修改已物化的派生文本时，Manager 应报告“实际值与标准计算值不一致”；后续成功发布以标准计算值覆盖。

## 6. 全局 DWG 命名模板

### 6.1 单一模板与字段范围

每个标准必须且只能定义一条全项目 DWG 命名模板，应用于所有子集主 DWG。模板是标准驱动新建流程中的唯一命名来源，不再隐式从基础模板文件名、布局模板文件名或其他 DWG 提取项目级前缀。

允许字段只有：

- `subset.scope`：子集内图纸号范围，例如 `007-011`；
- `subset.name`：从 AcSm 子集 `Name` 解构后去除范围的可编辑名称；
- `subset.sequence`：子集在图纸集中的 1 起始物理顺序，包含不编号子集，与图纸流水号无关，可使用受控数字补零格式；
- 全部 `sheetset` 作用域属性，包括普通、映射和组合属性。

禁止引用任何 `sheet` 属性。DWG 命名是终端输出，不能被属性或其他规则引用。完整求值顺序为：

```text
普通 sheetset 属性 → sheetset 映射属性 → sheetset 组合属性 → DWG 命名
```

### 6.2 编辑器与预览

DWG 命名编辑器与组合属性编辑器使用相同骨架：左侧字段浏览器、右侧单行令牌编辑框、下方预览。固定文字可直接输入，字段以不可拆分令牌插入。sheetset 属性令牌内部保存 `property_id`，界面显示当前属性名。

标准编辑器显示一个明确标注为“示例”的文件名，并列出取样值：

- `subset.sequence = 1`，按令牌格式决定是否补零；
- `subset.scope` 使用与编号位数一致的范围，例如 `001-003`；
- `subset.name = 示例子集`；
- sheetset 属性按“默认值 → 枚举首项 → 示例占位值”取样。

从标准创建图纸集时必须使用真实 sheetset 值和全部子集生成权威预览，并在创建前检查所有结果。示例预览不得冒充工程结果。

### 6.3 默认模板与文件名安全

新建空白标准及从 DST 提取的标准草稿均预填：

```text
{subset.scope} {subset.name}
```

从 DST 提取时不根据现有文件名猜测规则。需要 `RQ-` 等专业前缀时，应显式引用 sheetset 属性，例如：

```text
{sheetset.专业代码}-{subset.scope} {subset.name}
```

模板只生成文件名主体，`.dwg` 由系统固定追加。结果必须满足：

- 主体非空且不自行包含 `.dwg` 扩展名；
- 不含目录分隔符、盘符、绝对/相对路径片段、控制字符或 Windows 文件名非法字符；
- 不是 Windows 保留设备名，不以空格或句点结尾；
- 包含 `.dwg` 后的文件名长度不超过 240；
- 系统不自动替换或删除非法字符，必须定位到模板或源字段并报告错误。

模板不强制包含 `subset.sequence` 或 `subset.scope`；若两者均未使用，发布标准时显示“可能产生重名”的 warning。创建具体项目时按 Windows 大小写不敏感语义检查全部目标路径，任何两个子集得到同一目标时以 `DWG_TARGET_COLLISION` 阻止创建。

## 7. 保存、发布与诊断

草稿允许保存未完成内容，但发布检查必须区分 error 与 warning。

### 7.1 阻断错误

- 属性当前名称或历史名称冲突；
- 非法作用域、类型转换或删除被引用属性；
- 枚举默认值不属于枚举列表；
- 映射源类型/作用域非法、源被重复占用、目标为空或枚举未覆盖；
- 组合字段越权、引用未知字段或上游无法计算；
- DWG 模板缺失、引用越权、结果非法或具体项目出现目标冲突。

### 7.2 非阻断警告

- 枚举列表变化后映射尚未确认；
- DWG 模板同时缺少 `subset.sequence` 和 `subset.scope`，只能在具体项目中证明唯一性。

问题必须可从发布检查返回普通属性行、派生属性行/编辑模态框或 DWG 命名令牌并聚焦。前端诊断不能取代后端发布门禁。

## 8. 兼容性与迁移

- 图纸标准包尚未形成任何对外发布版本或兼容承诺，因此直接更新当前 Schema v1 定义，不新增 v2、不保留旧规则兼容层，也不提供迁移器。
- 开发期旧草稿、旧包、数据库记录和测试夹具随实施同步重建；旧结构必须以明确 Schema 校验错误拒绝，不能按新模型猜测读取。
- 从本规范首次正式发布开始，已发布标准版本不可原地修改，后续不兼容变更必须升级 Schema 版本并提供明确兼容决策。
- 现有普通图纸集继续由 Manager 当前文本属性和受控命名规则处理，不因本规范改变。
- 标准驱动新建图纸集使用本文规则；创建后的持续约束由绑定标准工作区 Todo 后续立项。
- `sheet.name` 不属于系统字段；Sheet 系统字段固定为 `sheet.number` 和 `sheet.title`，布局名也不作为组合属性输入开放。

## 9. 测试与验收

至少覆盖：

1. 普通属性文本/枚举控件联动、全局重名、保留名称和引用删除保护；
2. 枚举项稳定 ID 在改名、增加、删除和排序后的映射保持与待确认状态；
3. 映射源类型、作用域和唯一性门禁，以及目标重复允许、目标空值阻断；
4. sheetset/sheet 组合字段可见性、`sheet.number`/`sheet.title`、空可选值和失败传播；
5. 属性改名按历史名称迁移并保留 DST 值与 AcSm GUID；
6. 派生属性物化、外部篡改诊断和失败时正式 DST 零改动；
7. DWG 编辑器令牌、示例预览、默认模板、补零序号、显式 sheetset 前缀及禁止 Sheet 字段；
8. 文件名非法字符、保留名、长度、尾随字符和大小写不敏感碰撞；
9. 模板缺少唯一性字段的发布 warning，以及具体创建时的全量冲突阻断；
10. 900×768、200% 缩放、浅深主题、纯键盘字段插入、模态焦点圈闭和错误跳转。

## 10. 非目标

- 子集自定义属性；
- 多套 DWG 命名模板、按子集类型分支或条件命名；
- Sheet 属性参与 DWG 命名；
- 组合属性引用组合属性；
- 日期格式化、通用公式、用户脚本或自由 JSON；
- 从已有 DWG 文件名反向推断标准模板；
- 创建后绑定标准工作区的持续锁定与事务改名实现。
