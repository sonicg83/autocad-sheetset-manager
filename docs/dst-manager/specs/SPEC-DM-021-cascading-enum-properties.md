# 图纸标准级联枚举属性规范

## 1. 目的与权威范围

本规范定义标准包中的第三区域「级联属性」：它是由用户输入、由上级普通枚举限定候选值、最终写入 DST 的单值属性。标准属性因此分为「普通属性（文本、枚举）」「级联属性」「派生属性（映射、组合）」三类。级联不使用中间的「道路分册」「燃气分册」属性；这类分组只存在于级联配置，不进入 DST。

本规范增量扩展 [SPEC-DM-017](SPEC-DM-017-standard-properties-and-dwg-naming.md) 的属性身份、编辑与求值契约，以及 [SPEC-DM-018](SPEC-DM-018-standard-driven-sheetset-creation-ui.md) 的项目信息、图纸组、XLSX 与创建门禁。标准身份、已发布包只读和受控发布仍以 [SPEC-DM-020](SPEC-DM-020-versionless-standard-identity-and-management.md) 与 [ARCH-DM-001](../architecture/ARCH-DM-001-dst-manager-mvp-baseline.md) 为准。本规范覆盖 `sheetset` 与 `sheet` 两种作用域的一层级联；创建完成后重新进入普通工作区的标准约束，仍由[绑定标准工作区待办](../../../.planning/todos/dst-manager/2026-09-22-bound-standard-workspace-semantics.md)承接。

## 2. 使用场景与边界

同一个图纸集可以只选一次 `sheetset`「专业名称」与「专业分册」：标准作者先建立普通枚举「专业名称」，枚举项为「道路」「燃气」等；再建立级联属性「专业分册」，将每个专业枚举项对应到若干分册候选。若标准将这两个属性定义为 `sheet`，创建时则由每个图纸组分别选择，组内生成的全部 Sheet 继承该组取值。两个专业下可以出现同名分册，选值始终与同一作用域、同一对象上的专业一起校验。

上级只能是同作用域的普通枚举：`sheetset` 级联引用 `sheetset` 普通枚举，`sheet` 级联引用 `sheet` 普通枚举。级联不能作为另一个级联的上级，也不允许跨作用域引用。映射的源仍只允许普通枚举；组合同级可引用已通过校验的级联值，`sheet` 组合仍可按原规则引用合法的 `sheetset` 字段。全局 DWG 命名仍只引用 `sheetset` 属性，不能引用 `sheet` 级联。求值顺序为：各作用域普通输入与级联输入校验 → 映射 → 组合 → DWG 命名。

## 3. 标准包数据契约

级联属性沿用普通属性的 `property_id`、名称、历史名称、描述、`scope` 和 `required`；`kind` 固定为 `cascade`，`scope` 只能是 `sheetset` 或 `sheet`。它有一个 `source_property_id`，指向同标准、同作用域的普通枚举属性；`default_value` 固定为空字符串，首版不提供级联默认值。

每个级联属性保存 `cascade_options` 有序行。每行的 `source_item_id` 引用上级枚举项的稳定 `enum_item_id`，`values` 保存该专业下有序、非空的分册文本数组。例如：

```json
{
  "property_id": "prop-volume",
  "name": "专业分册",
  "scope": "sheetset",
  "kind": "cascade",
  "required": true,
  "default_value": "",
  "source_property_id": "prop-major",
  "cascade_options": [
    {"source_item_id": "major-road", "values": ["分册一", "分册二", "分册三"]},
    {"source_item_id": "major-gas", "values": ["分册一", "分册二"]}
  ]
}
```

上例为 `sheetset` 作用域；图纸级级联使用同一结构，但级联与 `source_property_id` 指向的普通枚举都须为 `scope: "sheet"`。

逗号分隔仅是标准编辑器的输入形式，标准文档、API 和 `.dststandard` 包中的权威表示都是字符串数组，不保存逗号拼接值。编辑器接受半角逗号与全角逗号作为分隔符，逐项去掉首尾空白；空片段、同一行内去空白后大小写不敏感的重复值、包含逗号的选项都不能确认。不同专业的候选允许重复。用户输入的选项顺序即向导下拉顺序。选项文本按原样保存和写入 DST，不改大小写、不自动编号。

标准文档从当前 `schema_version: 3` 升为 `4`。已发布 v3 标准和包继续只读加载、导出及用于创建；新建标准、编辑保存的草稿与新发布包写 v4。现有 v3 草稿在读取时只转换内存模型，用户显式保存时才升级为 v4，不因只读列表或打开而改写磁盘。升级保留 UUID、名称、描述、属性和资产；旧格式不得按级联推断出新字段。v4 读取器对未知 `kind` 或不合法 `cascade_options` 明确报错，不按文本属性降级。

## 4. 标准编辑器

编辑分区中「普通属性」之后增加独立的「级联属性」，「派生属性」仍只包含映射与组合。级联列表显示名称、作用域、上级属性、上级枚举项数、必填状态、说明和编辑/删除操作。新建时作者先选择 `sheetset` 或 `sheet` 作用域，再从同作用域普通枚举中选上级；相同上级可以被多个级联属性复用。

级联编辑器在上方显示作用域与上级属性选择器，下方使用两列表格「上级枚举项｜级联候选值」。行由当前上级枚举项固定生成，左列只读，右列可输入以逗号分隔的候选值；行不支持独立增删或排序。源枚举项改名但 `enum_item_id` 不变时，原候选保留并显示新名称；源增加、删除或更换时，草稿可保存，但发布前必须处理缺行或过时行。编辑器提供明确的同步/确认动作，只保留仍匹配的源 ID 行，并在丢弃过时行前提示。切换上级或作用域时不得把旧候选自动套用到新源。

删除被级联引用的上级普通枚举属性必须阻断并显示引用的级联属性；删除级联属性仍受组合及 DWG 命名引用保护。发布检查至少阻断：上级不存在或类型/作用域错误、级联引用自身或其他级联、上级枚举没有项目、源项缺行/多行/过时行、某行无有效选项、级联非空默认值、单行空值或重复候选。草稿允许不完整配置，错误在发布检查中定位到级联属性和专业行。

新增稳定诊断码：`STANDARD_CASCADE_SOURCE_INVALID` 用于上级缺失、类型/作用域越界或级联链；`STANDARD_CASCADE_OPTIONS_INVALID` 用于缺行、多行、过时行或候选空值/重复；`STANDARD_CASCADE_VALUE_INVALID` 用于创建输入与当前上级不匹配。级联必填为空继续使用现有创建必填诊断；XLSX 错配使用 `CREATION_XLSX_CASCADE_VALUE_INVALID` 并携带工作表、行、列。诊断不得包含客户路径或候选之外的敏感内容。

## 5. 创建向导、预览与物化

`sheetset` 级联在「项目信息」页显示，`sheet` 级联在「图纸组编辑」页按组显示；两者都排在本作用域上级属性之后，都是可输入属性。未选上级值时级联控件置灰并提示先选择该上级属性，级联实际值为空。选定上级后，只显示对应行的候选；用户改变或清空上级时，界面立即清空同一对象中所有引用该上级的级联值并使旧预览失效，不自动选择第一项。若级联必填，控件和诊断采用与普通属性一致的必填语义。

创建草稿以级联 `property_id` 保存单个文本值：`sheetset` 级联位于 `sheetset_values`，`sheet` 级联位于对应图纸组的 `sheet_values`，并由该组全部 Sheet 继承。新增图纸组复制上一组的上级与级联值，首组的级联初值为空。批量修改上级时，仅清空被修改图纸组中依赖该上级的级联值；批量修改级联时，非空候选必须对所有选中组的当前上级都有效，否则整次操作拒绝且不部分应用，清空操作仍可执行。

草稿恢复、API 直接写入、XLSX 导入或标准变化导致旧值与上级不匹配时，系统保留原始输入供用户修正，展示对应项目字段或图纸组/字段诊断；禁用或无匹配选项的控件旁仍须显示该原值与清空入口，不得把错误值隐藏在下拉框内，也不得静默清空或改成首项。`sheetset` 实时派生求值、后端预览和最终创建均使用同一领域校验；`sheet` 值逐组校验并在预览中用于每张 Sheet 的计算。上级为空时级联必须为空；上级非空时非空级联值必须严格属于对应候选；必填级联不得为空。上级值本身不在普通枚举中时先报告上级错误，级联不据非法上级推断候选。

创建成功后，上级与级联值分别写入其本作用域的 DST 自定义属性：`sheetset` 值写图纸集，`sheet` 值写该组生成的每张 Sheet。配置中的候选行不物化为 DST 属性，也不产生额外 AcSm 节点。合法级联值可参与同级组合；只有 `sheetset` 级联可按现有字段范围参与 DWG 命名。任何级联错误均阻断创建，执行前重新核对草稿修订、标准快照与预览摘要。

## 6. XLSX 辅助输入

导出模板时，`sheetset` 级联在可见 `SheetSet` 工作表增加输入行，`sheet` 级联在可见 `Sheet` 工作表增加输入列；两者的上级继续使用普通枚举下拉。每个级联字段的 Data Validation 使用其所有上级分组候选按首次出现顺序去重后的静态下拉。模板不生成 `INDIRECT`、命名区域联动或业务公式，不显示内部 ID。候选提示只是录入辅助，粘贴仍可绕过。

导入端先读取完整 `SheetSet` 值和每个 `Sheet` 数据行，再分别按作用域校验上级与级联组合；错误定位到 `SheetSet` 级联的 B 列单元格，或 `Sheet` 的实际行列，并说明当前上级允许的选项。上级非法时优先定位上级单元格，避免重复报互相矛盾的错误。任一行错误都整批拒绝，原创建草稿不变；成功后与网页输入得到同一草稿、预览和最终 DST 值。

## 7. 兼容性与非目标

- 现有无级联的 v3 标准、已发布包和创建流程保持原行为；已发布标准内容不可原地修改。v4 包导入预检、确认、导出与标准快照须保留级联配置，不可丢行或重排。
- 当前绑定标准工作区恢复普通/枚举/派生约束的后续工作，在落地时也应包含级联属性；本次不承诺创建后普通工作区立即提供级联下拉。
- 首版不支持多级级联、跨作用域级联、级联默认值、级联作为映射源、Excel 动态联动下拉、按上级自动选择级联值、自由公式或中间分册属性。
- Web 前端负责即时清空和提示，后端负责标准发布、草稿预览、XLSX 导入与执行的最终校验；不得以 UI 控件或 Excel Data Validation 代替领域门禁。

## 8. 验收场景

1. 标准作者分别创建 `sheetset` 与 `sheet` 同级的普通枚举和级联属性；跨级源在草稿可诊断但不能发布。两组配置在草稿保存、重新打开、发布、导出再导入后均保持一致。
2. 源枚举项改名保留原行；新增、删除、更换源后发布检查准确定位缺失或过时行，删除被引用的源属性被阻断。
3. 项目信息页和图纸组页未选上级时对应级联置灰；选道路只见道路候选；更换上级只清空同一对象中的依赖值，其他图纸组不受影响。新增组复制合法配对，批量更改上级清空选中组的依赖值，批量设置级联不能产生部分成功。
4. 草稿恢复、API 直写与 XLSX 粘贴非法组合均被后端阻断，原值不被静默改写；XLSX 错误分别定位到 `SheetSet` 的 B 列或 `Sheet` 的具体行列，整批导入保持原草稿。
5. 预览、组合及合法作用域的 DWG 命名看到同一个有效级联值；最终 DST 仅在相应图纸集或 Sheet 节点写入上级与级联属性，不含候选分组中间属性。
6. v3 标准照常加载和创建；v3 草稿只读打开不改文件，显式保存升级 v4；未知 v4 属性种类明确拒绝。
