# 标准驱动新建图纸集 UI 规范

## 1. 目的与权威范围

本文定义 DST Manager 从**已发布图纸标准**创建新图纸集的首版界面与 XLSX 辅助输入契约。用户以界面逐项编辑为主，XLSX 用于批量录入；创建成功后进入普通 Manager 工作区。本规范只覆盖创建向导的交互、可见数据、导入行为与验收，不重复定义标准 Schema、属性求值、DWG 命名算法、CAD Worker 或发布事务。

- 欢迎页和标准库入口沿用 [SPEC-DM-016](SPEC-DM-016-drawing-standard-management-ui.md)。
- 标准发布版本身份、整数版本展示（`v<n>`）与工程绑定字符串沿用 [SPEC-DM-019](SPEC-DM-019-standard-version-and-package-import.md)；本规范只描述向导中的展示位置。
- 普通/派生属性与唯一 DWG 命名模板沿用 [SPEC-DM-017](SPEC-DM-017-standard-properties-and-dwg-naming.md)。
- 「不编号图纸」关键字的判定、补零和不占号语义沿用 [SPEC-DM-014](SPEC-DM-014-unnumbered-subset-keywords.md)。
- 后端创建链路和实施任务由 [PLAN-DM-036](../../../.planning/plans/dst-manager/PLAN-DM-036-standard-driven-sheetset-creation.md) 承接；创建所需最小 DST 骨架由 Manager 内置，见 [RFC-INT-003](../../integration/rfcs/RFC-INT-003-retire-builder-standard-driven-sheetset-creation.md) 的 2026-09-23 实施收敛。
- [四阶段交互 Demo](../mockups/SPEC-DM-018-creation-demo.html) 用模拟数据展示页面和关键状态，仅辅助评审；不生成真实 XLSX，也不调用创建 API。

设计意图是让用户在创建前完成项目属性、目标目录和图纸组配置，并在一张按图纸组汇总的权威预览表中检查结果。不在创建阶段要求用户逐张编辑图纸；需要差异化属性时，创建后到普通工作区修改。

## 2. 界面结构与进入方式

创建向导固定为四个阶段：

```text
选择标准 → 项目信息 → 图纸组 → 检查并创建
```

1. 欢迎页「创建新图纸集」进入第一阶段，只列出**已发布且依赖可用**的标准。无可用标准时说明原因并提供前往标准库的入口，不提供无标准创建。
2. 标准详情的「用于创建」固定所选 `standard_id` 与发布版本（展示为 `v<n>`，接口与草稿字段仍为裸整数），直接进入第二阶段；不得再要求重复选择。标准草稿不可用于创建。版本号不可由用户填写或预占，见 [SPEC-DM-019](SPEC-DM-019-standard-version-and-package-import.md) §2、§3。
3. 向导以可恢复创建草稿保存输入和当前阶段。重新进入时提示「继续草稿」或「重新开始」；后者须确认会放弃当前草稿输入。切换标准时提示并清除与新标准不兼容的字段、模板选择和预览，不静默迁移为看似有效的数据。
4. 各阶段可返回修改。第三阶段同时编辑图纸组、基础模板、布局模板和图幅，不另设模板阶段；第四阶段包含预览、确认及执行入口，不另设执行阶段。
5. 阶段门禁和最终值以后端草稿/预览响应为准；前端即时提示只帮助定位，不复制最终属性求值、编号或文件命名规则。任何输入变更立即使旧预览失效，并禁用「创建并打开图纸集」直至重新预览成功。

## 3. 项目信息

### 3.1 图纸集属性

按标准展示可输入的 `sheetset` 普通属性：文本用文本框，枚举用选项控件，标明必填与默认值。派生属性只读展示计算结果或待计算状态，不提供输入控件。标准字段名只是属性名，**不能**被当作项目文件夹名称的来源；「项目名称」「工程名称」或其他名称的属性均不得驱动目录名。

默认值只用于新建输入初值；用户主动清空后不得自动回填。前端可提示枚举与必填错误，后端在预览时给出最终诊断。

### 3.2 项目目录

界面让用户选择一个**已存在的上一级目录**，并在同一选择流程中提供可编辑的项目目录名，初值为「新建项目」，行为类似 Windows 的新建文件夹命名。界面展示拼接后的完整最终路径，用户可在创建前修改目录名；不得从图纸集自定义属性推断或同步该名称，也不自动追加「(2)」等后缀。

首版创建的 AutoCAD 图纸集名称（`AcSmSheetSet.Name`）取最终项目目录名，不增加第二个名称输入项；它与「项目名称」「工程名称」等自定义属性相互独立，创建成功后可在普通工作区修改。

目标仅可为尚不存在的新目录或已经存在的空目录。非空目录、文件同名、越界路径或非法 Windows 名称必须阻断并定位到路径输入；不能覆盖、合并或清空现有工程。预览和执行时都须重新检查目标状态，以防预览后被其他程序占用。

## 4. 图纸组编辑

### 4.1 一行一组

第三阶段按子集/图纸组编辑，不展开每张图纸。每组至少包含：

```text
图名（子集名） | 张数 | 基础模板 | 布局模板 | 图幅（所选布局名） | 标准定义的其他可输入 sheet 属性
```

一行对应一个子集和一个主 DWG；「张数」决定组内生成的 Sheet 与布局数量。创建阶段，同组全部图纸继承这一行的模板、图幅及其他输入属性。图号、最终图纸标题、布局名、DWG 文件名、映射/组合派生属性均非输入项。图纸组可按最终顺序调整；顺序变化使预览失效。

图名不能为空，张数为正整数；同一创建草稿内的图名按去首尾空格、大小写不敏感比较不得重复。重复时直接标错，不静默改名或附加序号。基础模板、布局模板、图幅须来自当前固定标准的可用资产及实际布局，组合关系以后端校验为准。

### 4.2 便捷操作

- **新建图纸组**：存在已有组时，以最近一个已创建图纸组的全部可编辑输入为初值复制，包括图名、张数、模板、图幅和其他 sheet 属性；新组取得新身份，立即选中图名输入供用户改名。若未改名而与原组重复，保持可编辑错误状态并禁止通过预览，不自动追加编号。首个图纸组采用标准默认值。
- **批量修改**：先选择多个图纸组，再选择一个字段及新值，一次应用到选中组。支持张数、基础模板、布局模板、图幅和所有可输入 sheet 属性；不支持批量修改图名或任何派生字段。当前值不一致时显示「值不相同」状态；清空字段必须是明确操作，不把未填写的批量编辑框当成清空命令。提交后对全部受影响组运行校验并使预览失效。
- 创建阶段不提供逐张差异化输入。创建成功后，如需不同图纸属性，用户到普通工作区修改。

## 5. XLSX 辅助输入

### 5.1 导出模板

从固定标准版本导出 XLSX 模板，沿用 legacy 样例的两类可见工作表布局，仅有 `SheetSet` 和 `Sheet` 两个**可见**工作表：

| 工作表 | 可见结构 | 内容 |
| --- | --- | --- |
| `SheetSet` | A 列属性名、B 列输入值 | 标准定义的可输入 `sheetset` 普通属性；另有固定「项目保存路径」行，输入**包含最终项目目录名的完整路径** |
| `Sheet` | 第一行为表头、后续一行一个图纸组 | `图名｜张数｜基础模板｜布局模板｜图幅｜其他可输入 sheet 属性` |

枚举、基础模板、布局模板、图幅配置 Excel Data Validation。允许隐藏技术工作表保存候选值、稳定属性/资产 ID、模板格式版本和标准身份；内部标识不显示在业务表。模板不包含派生属性列，也不在业务单元格中生成计算公式。首版不做依赖公式驱动的联动下拉：候选项可按标准列出，模板/图幅实际组合由导入端校验。Excel 的 Data Validation 可被粘贴绕过，不能取代后端校验。

### 5.2 导入语义

导入仅接受与当前草稿固定标准版本匹配的模板。`SheetSet` 的「项目保存路径」直接解释为完整最终路径，不再附加由属性值推断的文件夹名；与 UI 的「上级目录 + 可编辑目录名」汇合为同一个最终路径字段。`Sheet` 每行创建一个图纸组，按行序决定组序，张数展开为同属性的多张图纸。

导入采用**全量覆盖**，不计算或展示差异：如果当前草稿已有项目信息或图纸组输入，先提醒「导入将覆盖当前项目属性、项目路径和全部图纸组」，用户确认后才解析并替换；取消则保留草稿。校验失败时整个草稿原样保留，按工作表、行、列和字段显示诊断并可定位；成功时一次性替换上述输入、保留固定标准身份，预览失效。不得部分导入或保留旧行。

拒绝公式单元格、未知/重复表头、派生字段输入、无效枚举、失效资产、非法张数、越界/危险路径和超出受控规模的工作簿；导入不执行 Excel 公式、宏或外部链接。模板中的显示文案不作为稳定字段身份，实际映射以受控元数据和当前标准为准。

## 6. 检查并创建

### 6.1 预览主体

预览只呈现**每个图纸组一行**，不在主表中平铺每张 Sheet。顶部显示固定标准及版本（`v<n>`，取自服务端分配的整数发布版本）、最终项目路径、图纸组数、总张数、DWG 数、当前编号设置摘要和检查状态。主表固定列为：

```text
图纸组 | 图纸范围 | 图纸 | 张数 | 文件名 | 基础模板 | 布局模板 | 图幅 | 标准定义的其他 sheet 属性列
```

- 「图纸范围」来自组内实际 `sheet.number` 的首末值，例如 `01-03`。命中设置中「不编号图纸」关键字的子集，组内全部图纸取项目/标准编号位数的零值；该列只显示单值，例如 `00`，**不**显示 `00-00`，且不消耗后续序号。
- 「图纸」显示该组实际图纸标题的紧凑范围：无尾序号时为图名，例如「平面图」；启用尾序号且组内多张时，使用实际首末标题压缩为「平面图 (一)-(三)」。不得仅按张数猜测序号，标题结果以后端派生为准。
- 「文件名」是标准唯一 DWG 命名模板对该组真实数据求值后的结果，带 `.dwg`；不能从图纸范围或示例模板名在前端拼凑。
- 「基础模板」「布局模板」「图幅」显示该组最终选择；图幅为所选布局名，不是纸张尺寸的自由文本。
- 「其他图纸属性」列由标准动态生成，包含输入与派生的 `sheet` 属性。组内所有 Sheet 的实际值相同，单元格直接显示值；不相同时显示**第一张图纸的实际值 + 可点击的「…」**。首张值为空时明确显示「（空）…」，不能只给省略号。

点击某个属性单元格的「…」打开模态对话框，标题标明图纸组与属性名，按组内顺序列出**全部图纸**的「图号｜图纸标题｜该属性实际值」。模态只展示所点属性，不改变主表一组一行的结构；支持键盘打开、Esc/关闭按钮退出、焦点圈定与关闭后返回触发按钮。主表可在内部横向滚动，首列图纸组保持可见；900×768 视口下不得让页面整体出现横向滚动。

主表不提供「布局」列，但布局名、DWG 引用、重复名称和资产可用性仍必须参与后端预览/创建校验；移除列不等于跳过校验。

### 6.2 诊断、设置与执行

预览诊断区区分阻断错误与非阻断提示，错误可返回并定位到项目字段、图纸组行、模板/图幅或 XLSX 导入位置。编号设置（包括 `unnumbered_subset_keywords`、标题尾序号开关和类型）、标准发布版本、草稿修订、目标状态或标准资产变化后，原 `preview_digest` 失效；执行必须重新核对有效配置和全部输出，不得凭旧预览创建。

仅当后端预览无阻断错误时可点击「创建并打开图纸集」。执行沿用全局任务进度展示；成功后切换到新建项目的普通 Manager 工作区。失败时保留创建草稿和可读诊断，允许修正后重新预览/重试；目标不得留下半成品。对于不编号组且关闭标题尾序号导致同名布局等既有冲突，预览直接阻断，不自动改写标题或图号。

## 7. 界面与安全边界

继承 [ARCH-DM-007](../architecture/ARCH-DM-007-frontend-ui-foundations.md) 的视觉令牌、浅深主题、共享控件与可访问性要求。四阶段标题和当前状态应可读，主动作与返回动作稳定；表格和模态需有明确表头、键盘焦点、错误关联及屏幕阅读器名称。向导离开或重新开始不得静默丢失草稿。

前端不直接写工程目录、DST 或 DWG；预览不启动 CAD。XLSX 是不可信输入，不得把其中的路径、单元格内容或文件名拼接成 Shell、SCR 或 SQL。正式创建只使用固定 Worker 协议、标准包受控资产及可回滚发布事务。

## 8. 验收场景

1. 从欢迎页选已发布标准进入第一阶段；从标准详情「用于创建」直接进入项目信息；草稿恢复和切换标准均按提示处理，不误用标准草稿。
2. UI 选择上级目录并修改默认「新建项目」目录名；XLSX 输入同一个完整最终路径；两种输入得到同一创建草稿字段，`AcSmSheetSet.Name` 均取最终目录名，均不引用「工程名称」等自定义属性来组装路径或图纸集名称。
3. 新建第二组复制上一组全部可输入值并聚焦图名；重复图名阻断且不自动改名。批量修改张数、模板、图幅或 sheet 属性只影响选中组，明确清空与混合值状态可区分。
4. 标准枚举与模板候选在导出 XLSX 中有 Data Validation；可见表只有 `SheetSet`/`Sheet`；无派生列与业务公式；合法工作簿按组行展开，与界面输入得到同一预览。
5. 导入前提醒全量覆盖；取消或任一错误保持原草稿；成功后旧项目属性、路径及全部组被替换，且旧预览失效。错误能定位工作表/行/列。
6. 不编号图纸组显示 `00` 单值并不占号；其后两组分别正确显示 `01-03`、`04-05`；修改关键字、后缀或标准位数后，旧预览不可执行。
7. 预览表每组一行，文件名来自真实 DWG 命名模板；同组属性同值直接显示，不同值显示首张值加「…」；点击后模态列出该组全部 Sheet 的图号、标题和值，关闭后焦点回到链接。
8. 目标非空、标准/资产变化、派生失败、文件名冲突或布局冲突时阻断创建；成功切换工作区，失败保留草稿且没有半成品。
9. 浅色/深色、900×768、键盘和模态焦点回归通过；主表自身可横向滚动，页面整体不横向溢出。
10. 向导中展示的标准版本统一为 `v<n>`；固定标准身份与快照在 XLSX 元数据、预览和执行之间一致，版本或标准内容变化使旧预览失效。

## 9. 非目标

- 创建阶段逐张编辑图纸属性、模板或布局；
- XLSX 内计算派生属性、联动公式、差异比较或部分合并；
- 自动替用户重命名冲突图纸组、文件或项目目录；
- 用图纸集属性推断文件夹名；
- 在预览主表逐张展开 Sheet 或增加布局列；
- 改写标准属性、编号、不编号或 DWG 命名的既有权威算法。
