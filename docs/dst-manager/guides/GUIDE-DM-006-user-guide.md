# DST Manager 用户使用指南

## 适用范围

本指南面向 DST Manager 的最终用户（设计人员与项目负责人），说明从安装、打开图纸集到日常受控编辑、发布和故障处理的完整操作流程。开发环境的搭建、测试与打包流程不在本指南范围内，见仓库根目录 `README.md`。

本指南描述的行为对应 `v0.3.5`。界面文案以中文界面为准；切换到英文界面后按钮位置不变，仅文案不同。

## 前置条件

- Windows 10/11 x64 操作系统。
- 本机已安装 AutoCAD 2015–2024 中的某个版本（2015–2019 走 2016 兼容组，2020–2024 走 2020 兼容组；AutoCAD 2025 及以上暂不支持）。只做浏览和编辑草稿不启动 AutoCAD；执行需要 CAD 的操作（布局重命名、重建等）时会调用对应版本的 Core Console。
- 已获取分发包 `dst-manager-v<版本>-win64.zip`。
- 对工程文件有写权限；DST 文件所在磁盘有足够空间保存快照与修订记录。

## 安装与首次配置

1. 将 `dst-manager-v<版本>-win64.zip` 解压到任意本地目录（建议不要解压到需要管理员权限写入的目录，如 `C:\Program Files`）。
2. 运行程序目录内的 `setup.bat`：
   - 自动通过注册表和默认安装目录搜索本机 `accoreconsole.exe`，并把找到的路径按兼容组写入 exe 同级的 `.env`。
   - 幂等执行：已有配置不会被覆盖；AutoCAD 2013/2014 会写入 2016 组但附兼容性警告。
   - 如果本机有多个 AutoCAD 版本或搜索失败，可手工编辑 `.env` 中对应的 `autocad_2016_console` / `autocad_2020_console` 条目。
3. 双击 `dst-manager.exe` 启动。桌面壳无终端黑窗；同一时间只允许一个实例，重复启动会把已有窗口还原置前。

数据目录说明（均不在程序目录内，更新 zip 不会覆盖）：

| 位置 | 内容 |
| --- | --- |
| `%LOCALAPPDATA%\dst-manager\data\` | 应用数据（任务索引、修订记录等） |
| `%LOCALAPPDATA%\dst-manager\drafts\` | 未发布的编辑草稿 |
| `%LOCALAPPDATA%\dst-manager\logs\dst-manager.log` 与 `worker.log` | 壳与 Worker 运行日志 |

## 打开图纸集

1. 启动后进入"打开图纸集"欢迎页：输入 `.dst` 文件的绝对路径，点击"选择 DST 文件"从文件对话框选择，或直接把 `.dst` 文件拖入窗口。
2. 打开后进入工作区，顶部为三个功能页签：**① 图纸**、**② 属性**、**③ 修订历史**。
3. 若存在未发布的草稿，打开工作区时会提示恢复草稿或重新开始。

安全边界：只读浏览不会创建任何辅助目录，也不会修改 DST/DWG 或其时间戳；只有"确认写入"后的正式发布才会改动工程文件，且发布前会保留完整的 before 快照。

## 日常工作流程

DST Manager 的核心工作流是 **编辑 → 草稿 → 预览 → 确认写入（发布）**：

1. **编辑**：在图纸页或属性页进行的所有结构修改（新增/删除/重命名、移动、属性修改等）都不会立即写盘，而是进入底部操作区的**草稿栈**。草稿跨会话持久保存，程序中途关闭不会丢失。
2. **撤销/重做**：操作区提供撤销与重做按钮；草稿指示器（"草稿 {n}/{m}"）显示当前浏览位置。
3. **预览变更**：点击"预览变更"生成完整的修改预览，在右侧任务浮层的"修改预览"页签中查看。预览过期的（例如基准已变化）必须重新预览，界面会以"预览已失效"提示。
4. **确认写入**：预览确认无误后点击"确认写入"。系统依次执行：基准修订校验 → 暂存 → （需要时）CAD Worker 执行 → 结果验证 → 整批发布。任务状态在任务浮层"实施进度"页签实时更新（排队/暂存/CAD 执行/验证/发布中），完成或失败都会弹出通知。
5. **失败恢复**：任一环节失败时，整批恢复为发布前状态，before 快照永久保留；可修复的问题会进入任务浮层"诊断"页签并引导修复流程。

按钮不可用时会给出原因（如"任务进行中""请先预览""预览已失效""需先修复"），按提示处理即可。

### 草稿异常

- **草稿已过期**：草稿基准或修复状态已变化，只能查看旧意图、手工重做或丢弃，程序不会自动 rebase。
- **草稿损坏**：损坏草稿会被自动隔离并提示，可安全重新开始编辑。
- **其他窗口冲突**：草稿已在其他窗口更新时，当前窗口禁止覆盖，需重新打开工作区。

## 图纸页

图纸页是日常编辑的主界面，左树右表：

- **左侧树**：按子集层级浏览图纸集；子集支持展开/收起、新增、重命名、整体删除等受控操作。
- **右侧主表**：图纸列表，支持显示列配置、分页缓冲编辑、参照插入、批量操作与删除。编辑结果即时进入草稿栈。
- **命名规则**：图号、范围、标题、后缀和文件/布局命名均由统一规则派生，手工只输入业务语义部分；"不编号图纸"的行为由设置中心的"不编号图纸关键字"控制（见下文）。

## 属性页

属性页按分区查看和编辑图纸集、子集与图纸的属性。右侧属性值面板支持两列/四列切换（四列在宽窗口下生效）；名称列整行显示，长值自动跨列。属性修改同样先进入草稿，经预览发布后才写回 DST。

## 修订历史

- 每次成功发布都会生成一条修订记录，包含输入、执行计划、脚本、日志与 manifest。
- 在修订历史页签中可查看历史记录，并可选择某个版本生成**恢复预览**；确认后按同一发布事务流程执行恢复。
- 恢复与发布一样可回滚：失败时整批恢复原状。

## 图纸目录导出

图纸目录是内置扩展，在设置中心的扩展卡片中可配置全局选项：

- **输出图纸过滤**：图名命中任一关键词的图纸不写入目录；被过滤时业务页会显示"已过滤 N 张图纸"。
- **字段引用与数字格式码**：目录字段可引用图纸集/图纸属性，字段尾部可追加 `:0{n}` 格式码控制前导零补齐等输出格式；字段浏览器提供格式入口。
- 导出结果为 XLSX 文件，只做只读导出，不修改 DST/DWG、不写回属性值、不触发重编号。

## 设置中心

点击顶栏齿轮图标打开设置中心（未打开 DST 时也可配置）。共 13 项配置，按分组显示：

- **界面语言**：中文/英文，立即生效。
- **界面主题**：浅色/深色，持久保存；顶栏主题按钮只做会话级临时切换，重启后回到配置中心保存的主题。
- **AutoCAD 版本**：2016/2020。所有预览、布局读取与执行统一使用此版本；切换版本会使既有结构投影失效并提示重新预览。
- **编号规则**：含"不编号图纸关键字"——子集标题（大小写不敏感）包含任一关键字时，该子集整体不编号（图号为 `000` 单值）且不消耗序号；关键字为空则完全保持常规行为。
- **扩展配置**：各内置扩展（如图纸目录）在此提供"配置"入口。

配置保存即时生效并跨 API/Worker 进程传播；`settings.json` 只保存显式修改过的项，其余继承默认值。

## 自检与日常确认

- `dst-manager.exe doctor`：命令行自检，核对 AutoCAD 探测结果、数据目录与配置有效性；结果同时写入 `%LOCALAPPDATA%\dst-manager\logs\doctor-last.json`。
- 打开工作区后，图纸树与主表显示的即为当前 DST 的受控投影；发布成功后再打开 AutoCAD Sheet Set Manager，可交叉核对结构一致性。

## 故障处理

| 现象 | 处理方式 |
| --- | --- |
| `setup.bat` 找不到 AutoCAD | 手工编辑 `.env`，把 `accoreconsole.exe` 完整路径写入对应兼容组条目 |
| 双击启动无窗口或异常退出 | 查看 `%LOCALAPPDATA%\dst-manager\logs\dst-manager.log`；排障时把 `dst-manager.log`、`worker.log` 与 `doctor-last.json` 一起反馈 |
| CAD 任务卡在排队 | Worker 未运行或 Core Console 路径无效；运行 `doctor` 核对版本配置，重启程序 |
| CAD 执行失败 | 整批已恢复发布前状态；查看任务浮层"诊断"页签的错误码与说明，按引导修复后重试 |
| 提示"预览已失效" | 基准或修复状态已变化，重新点击"预览变更" |
| 提示"草稿已过期" | 草稿不可自动恢复；查看旧意图后手工重做或丢弃草稿 |
| 打开 .dst 报结构问题 | 程序支持可修复加载，按任务浮层"诊断"页签的修复引导执行；修复本身也走预览-发布流程 |
| 端口/实例异常（命令行模式） | 端口被无关程序占用时换 `-Port`；检测到遗留 Worker 先执行 Stop，确认状态后再启动 |
| 数据库结构漂移（`DATABASE_SCHEMA_DRIFT`） | 仅测试环境可删除 `.dst-manager-data/dst-manager.db` 后重启；生产数据不要手工删除数据库文件 |
