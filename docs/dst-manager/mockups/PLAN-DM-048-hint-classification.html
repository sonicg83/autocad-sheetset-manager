提示职责

Lead
仅解释不自明的页面或区块目的；自明标题不重复说明。
Help
补充字段规则或级联来源；只关联受影响控件或字段组。
Status
显示编辑、加载、保存或任务状态；动态状态只使用一个主要播报来源。
Banner
notice success warning error
流程级结果。notice 使用既有 info 色义；所有 tone 均保留可读文字。
Error
关联字段或行，说明原因；invalid 与描述引用同时存在。
