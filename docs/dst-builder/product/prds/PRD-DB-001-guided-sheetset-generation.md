# 引导式图纸集生成产品需求

> **封口说明（2026-09-21）：** 本文档描述已退场的 DST Builder 产品，仅作为历史资料保留，不再作为现役实现依据；替代方向见 [RFC-INT-003](../../../integration/rfcs/RFC-INT-003-retire-builder-standard-driven-sheetset-creation.md)、[PLAN-DM-035](../../../../.planning/plans/dst-manager/PLAN-DM-035-drawing-standard-platform.md) 与 [PLAN-DM-036](../../../../.planning/plans/dst-manager/PLAN-DM-036-standard-driven-sheetset-creation.md)。

## 1. 背景

旧图纸集生成链路以 Excel、PowerShell/WPF、Core Console 和多个 AutoCAD 插件串联完成。它已经证明业务可行，但业务规则、界面事件、路径操作和 CAD 命令耦合，缺少稳定的项目事实源、完整预览和可复现构建记录。

DST Manager 已验证本地 WebView2 桌面壳、受控 CAD Worker、DST/AcSm 校验、草稿、任务、Artifact 和可恢复发布等能力。DST Builder 在这些工程经验上从零设计新的生成型产品，不复制 Manager 的编辑型工作区，也不承担旧运行时兼容。

## 2. 目标用户

- 需要从项目资料创建首版 AutoCAD 图纸集的工程设计人员；
- 熟悉图号、图名、模板和图纸成果，但不应被要求理解 AcSm XML、Handle、SCR 或任务状态机；
- 首版假设单人在一台 Windows 11 工作站上完成一个项目的建模、构建和交付。

## 3. 问题

- 用户难以判断输入是否完整，错误经常在 AutoCAD 已运行后才暴露；
- Excel 同时承担界面、数据、规则和交换格式，难以表达修订、审计和资产版本；
- 构建过程缺少一份用户可审阅、机器可复现的完整计划；
- 失败可能留下难以判断是否可用的半成品。

## 4. 目标

- 通过可保存、可恢复的分步向导引导用户完成首版图纸集生产；
- 以应用内项目模型作为唯一事实源，以 Excel 作为兼容输入和交换格式；
- 在启动 AutoCAD 前生成并确认不可变 `GenerationPlan`；
- 生成经过真实验证的 DWG、DST 和伴随成果；
- 把 `sheetset.dst`、DWG 与图纸目录 XLSX 发布到目标目录，由 DST Manager 直接打开；
- 首版本地交付，但保持未来替换数据库、Artifact Store 和 CAD 执行器的端口。

## 5. 非目标

- 多用户协作、账号、RBAC、DM8、RustFS 或跨机器 Worker；
- 旧 PowerShell/WPF、旧数据库、旧 API 或旧项目文件的兼容运行；
- 以旧 `UtilityClass.dll` 作为 DST 生成回退；
- `SetDataLink`、`SetViews`、`SetViewPort`、`Transform`、`CoordinateDimension` 等外围插件迁移；
- Builder 与 Manager 的隐式双向同步；
- 绕过向导的专家自由模式。

## 6. 核心用户流程

### 6.1 创建项目

- 用户可以新建空白项目、导入旧 Excel，或复制已有 Builder 项目。
- 用户填写工程名称、阶段、专业和成果位置。
- 外部输入纳入项目资产并计算哈希；项目后续构建不依赖易漂移的外部绝对路径。

### 6.2 配置项目规则

- 配置编号结构、位数、特殊图纸规则、人员和专业字典。
- 定义图纸集级与图纸级自定义字段。
- 每项规则提供示例结果和就地校验，不要求用户理解内部表达式。

### 6.3 编排图纸

- 用户按图纸分组录入张数、名称、范围和属性。
- 支持从 Excel/CSV 多单元格粘贴。
- 系统实时展开最终单张图纸，并提示冲突、断号、重复和缺失字段。

### 6.4 匹配模板与资产

- 为图纸组选择基础 DWG、布局模板、图幅和附带资产。
- 在构建前检查模板文件、布局、字体、打印设置和 AutoCAD 兼容性。
- 缺失项显示明确的定位和修复动作。

### 6.5 构建前检查

- 从不可变项目修订生成 `GenerationPlan`。
- 展示最终图纸、DWG、布局、DST 属性和伴随成果清单。
- 诊断分为“必须修复”“建议确认”和“信息”。
- 用户明确确认计划后才能开始构建。

### 6.6 构建成果

- 展示当前阶段、总进度、当前 DWG、耗时和诊断。
- 支持安全取消；失败后保留诊断并提供可执行的恢复动作。
- 构建期间当前修订只读；用户需要修改时终止当前流程并创建新修订。

### 6.7 验收

- 校验布局、Handle、DST 引用、成果数量和文件哈希。
- 原子发布正式成果包。
- 在目标目录中直接得到 `sheetset.dst`，并由 DST Manager 打开验证。

## 7. 引导界面要求

- 左侧始终显示六个步骤及其未开始、进行中、已完成、警告或阻断状态。
- 中间区域只承载当前步骤的主要任务。
- 右侧显示当前步骤说明、示例和问题摘要。
- 底部固定提供“上一步”“保存退出”“继续”等上下文动作。
- 顶部显示项目名称、保存状态、AutoCAD 环境状态和设置入口。
- 已完成步骤可以返回；未满足前置条件的后续步骤不可进入。
- 草稿自动保存，重启后恢复到上次步骤和编辑上下文。
- 字段旁保留内联错误；提交失败时把焦点移到可链接至具体字段的错误摘要。
- 关键错误不得只通过 Toast 或颜色表达，必须同时提供文字、图标和恢复动作。
- 支持键盘完成主流程；焦点不可被固定操作栏或浮层遮挡。
- 继承 DST Manager 的语义令牌、双主题、基础组件和可访问性质量标准，但不复制其三标签页面状态机。

## 8. 项目与修订需求

- 每个项目使用用户选择的自包含目录，核心数据库文件名为 `project.dstb`。
- 应用设置、最近项目和窗口偏好位于 `%LOCALAPPDATA%\dst-builder\`。
- 日常编辑写入可变草稿；进入构建前检查时提交不可变 `ProjectRevision`。
- `GenerationPlan` 固定引用项目修订、模板和资产版本。
- 修改任何业务数据后必须产生新的项目修订和计划。
- 每个 `BuildRun` 和 `attempt` 保留独立身份、状态、日志与诊断，不覆盖失败历史。

## 9. 构建与成果需求

构建按以下阶段执行：

```text
DRAFT → REVISION_READY → PLANNED → QUEUED → PREPARING
→ BUILDING_DWG → BUILDING_DST → VERIFYING → PUBLISHING → SUCCEEDED
```

终止状态为 `FAILED` 或 `CANCELLED`。

- 所有处理发生在隔离构建目录。
- 一个必需 DWG 任务失败即阻止 DST 和正式成果发布。
- 发布事务必须保证目标成果要么保持旧版本，要么完整成为新版本。
- 进程崩溃后不续跑半完成 CAD 命令；启动恢复完成现场收敛后创建新 attempt。
- 用户输入不得直接拼接为 SCR、Shell 命令或未验证路径。

正式成果目标目录直接包含三个文件，没有包装子目录：

```text
<target>/
├─ sheetset.dst
├─ <sheet-number> <title>.dwg
└─ 图纸目录.xlsx
```

- 目标目录中的三件套即本次全部交付成果，整体复制后可脱离 Builder 使用。
- DST 对 DWG 的引用在目标目录内按相对文件名解析，与目录名无关。
- 不生成清单或校验报告文件；用户自行放入的其他文件不影响交付。

## 10. 交付与接管需求

- Builder 只在目标目录产出一套完整成果，构建成功即交付完成，不阻止用户在其中自行增加文件。
- Manager 通过打开成果目录中的 DST 接管项目，从磁盘现状建立工作区，不校验成果来源，也不要求成果保持发布时的字节不变。
- 两个产品之间不交换包级标识、清单或哈希，DST 文件是唯一接口。

## 11. 验收标准

### AC-001：完整引导流程

用户能够创建或导入项目，依次完成六个步骤；退出并重启后恢复原步骤、草稿和问题状态。

### AC-002：确定性计划

相同项目修订、资产版本和规则版本产生相同规范化 `GenerationPlan` 和计划哈希；任何输入变化产生新修订。

### AC-003：真实 CAD 结果

AutoCAD 2016 与 2020 均能完成最小和标准黄金项目；DWG 布局名、顺序、数量和 Handle 与计划一致。

### AC-004：DST 正确性

生成的 DST 通过 Schema 与契约校验，可由对应版本 AutoCAD Sheet Set Manager 打开，且所有图纸引用解析到成果目录内实际 DWG 和布局。

### AC-005：正式成果目录

成果目标目录直接包含 `sheetset.dst`、构建后的 DWG 和 `图纸目录.xlsx`，整体复制后可脱离 Builder 使用；目标目录含用户自有文件时，重新构建的同名目标仍按目标已存在拒绝，不得覆盖。

### AC-006：失败安全

输入错误在 AutoCAD 启动前报告；CAD、DST、校验或发布任一步失败均不产生半成品正式成果；故障注入后目标目录保持一致状态。

### AC-007：可访问性与桌面验收

键盘操作、错误聚焦、浅深主题、最小支持视口和 200% 缩放通过自动检查；打包后的 Windows 桌面壳使用真实项目完成主流程验收。
